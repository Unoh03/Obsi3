# Obsi3

클라우드 보안 엔지니어링을 공부하며 만든 개인 Obsidian vault입니다.

리눅스, 네트워크, 시스템·웹 보안, AWS, Terraform, Kubernetes/EKS, 자격증, 팀 프로젝트와 취업 준비 자료를 한곳에서 연결해 관리합니다. 완성된 교재만 모은 문서 사이트라기보다 **수업 내용, 직접 실행한 결과, 시행착오와 검증 증거를 함께 보존하는 학습 저장소**에 가깝습니다.

## 읽는 방법

### Obsidian으로 열기

1. 이 저장소를 clone 또는 download합니다.
2. [Obsidian](https://obsidian.md/)을 설치합니다.
3. 저장소 폴더를 Obsidian vault로 엽니다.
4. [Home](00_index/Home.md)부터 탐색합니다.

이 Vault의 기본 탐색 경로는 다음과 같습니다.

```text
Home
→ 영역 목차
→ 주제 또는 프로젝트 MOC
→ 실제 노트
```

Obsidian으로 열면 wiki link, 이미지 embed, PDF, backlinks, graph view와 MOC 기반 탐색을 온전히 사용할 수 있습니다.

### GitHub에서 보는 경우

GitHub에서도 Markdown 파일은 열 수 있지만, 다음 Obsidian 전용 기능은 완전히 동작하지 않을 수 있습니다.

- `[[wiki link]]`가 일반 링크처럼 열리지 않을 수 있습니다.
- 이미지, PDF와 로컬 첨부 파일을 따라가기 불편할 수 있습니다.
- backlinks, graph view, templates와 community plugin 기능은 Obsidian 기준입니다.
- 일부 노트는 완성된 글이 아니라 수업 메모, 실습 로그 또는 초안입니다.

링크가 이상하게 보이면 Obsidian에서 Vault를 열고 [Home](00_index/Home.md)부터 따라가는 편이 가장 정확합니다.

## 노트의 성격

- **개념 노트** — 여러 상황에서 다시 쓸 수 있도록 원리와 판단 기준을 정리합니다.
- **실습 노트** — 명령, 실행 결과, 실수, 수정 과정과 최종 관찰을 기록합니다.
- **트러블슈팅 노트** — 증상, 가설, 확인 명령, 원인, 조치와 검증을 연결합니다.
- **Source Digest** — PDF 등 원자료의 페이지·도식·불확실성을 보존해 후속 학습 노트의 근거로 사용합니다.
- **프로젝트 노트** — 요구사항, 팀 결정, 개인 기여, 구현 결과와 증거를 구분합니다.
- **MOC/목차** — 긴 본문을 담기보다 현재 경로와 실제 노트로 가는 진입점을 관리합니다.

노트의 `status`가 `draft` 또는 `active`라면 작성 중일 수 있습니다. 실제 실행 결과, 강의 원문, 공식 문서와 해석은 가능한 한 구분해서 기록합니다.

## 공유 시 주의사항

이 Vault는 개인 학습용으로 시작했으므로 일부 파일은 수업 맥락을 알아야 이해하기 쉽습니다.

- 자료를 재사용하거나 공유하기 전에 개인 정리, 강의 자료, 스크린샷 또는 외부 자료인지 확인해야 합니다.
- 강의 PDF와 실습용 다운로드 파일에는 별도의 저작권 또는 수업용 제한이 있을 수 있습니다.
- 오래된 실습 노트나 캡처에 보이는 비밀번호, Token, Cookie, Session ID 등의 값은 재사용 가능한 예시로 취급하면 안 됩니다.
- 실제 자격증명, private key, kubeconfig와 운영 Secret은 기록 대상으로 삼지 않습니다.

## Obsidian 및 AI 작업 규칙

- 시작 위치: `00_index/Home.md`
- 템플릿 폴더: `90_템플릿`
- community plugin은 새 환경에서 직접 다시 설치해야 할 수 있습니다.
- 개인 작업 화면 상태와 Secret이 포함될 수 있는 설정은 공유 대상이 아닙니다.
- ChatGPT, Codex, Claude, Gemini 같은 에이전트가 이 저장소를 수정할 때의 규칙은 [AGENTS.md](AGENTS.md)를 따릅니다.
