# 메이플 AI 데이터 목차

AI에는 이 안내와 실행 마지막에 표시되는 날짜 포함 전달본(`output/exports/ai-context-*.json`) 하나를 제공한다. MOC는 데이터를 포함하지 않으며, 아래 경로는 함께 제공한 JSON 내부 경로다. 로컬 파일 링크만 보내서는 외부 AI가 그 파일을 읽을 수 없다.

## 읽기 순서

| 순서 | JSON 경로 | 확인할 것 |
|---|---|---|
| 1 | `metadata` | 캐릭터, 수집 시작·종료 시각, 원본 SHA-256. 가장 최근에 첨부한 파일인지 먼저 확인 |
| 2 | `quality` | 오류·누락·partial, 데이터 기준 시각, `assessment`의 검증 범위와 미확인 사항 |
| 3 | `actual` | API가 반환한 활성 상태. `stat.values`에 장비 등의 효과를 다시 더하지 않음 |
| 4 | `presets` | 저장된 대안 설정. 각 프리셋을 착용했을 때의 최종 스탯은 아님 |
| 5 | `user_context` (있을 때) | 사용자가 설명한 용도와 프리셋 경로. `data_presence` 및 설명 기록일 확인. API 사실과 구분 |
| 6 | `changes_since_previous` | 이전 수집과의 차이. 강화·프리셋 전환 등 변화 원인은 별도 확인 |

## 저장 프리셋 찾기

| 내용 | JSON 경로 |
|---|---|
| 하이퍼 스탯 | `presets.hyper_stat.hyper_stat_preset_1` ~ `_3` |
| 어빌리티 | `presets.ability.ability_preset_1` ~ `_3` |
| 장비 / 칭호 | `presets.item_equipment.item_equipment_preset_1` ~ `_3` / `title_preset1` ~ `3` |
| 링크 | `presets.link_skill` |
| V 매트릭스 / HEXA 스탯 | `presets.vmatrix` / `presets.hexamatrix_stat` |
| 유니온 상태 스탯 | **`presets.union_raider.union_state_stat_preset`** — 배열의 `preset_no`로 찾음 |

구형 `union_raider_preset_1~5`가 null이어도 새 유니온 상태 스탯 프리셋이 있을 수 있다. 새 필드부터 확인하고, 구형 필드의 null을 전체 프리셋 누락으로 해석하지 않는다. [공식 2026년 6월 개편 안내](https://openapi.nexon.com/support/notice/3477756/)

활성 번호는 각 `actual` 섹션의 selector를 확인한다. 서로 다른 종류의 프리셋 번호가 항상 같다고 가정하지 않는다. 보스·사냥 용도는 사용자가 알려준 설정에 연결하며 임의로 추정하지 않는다.

현재 최종 스탯은 한 상태만 수집한다. 저장된 대안 프리셋은 구성 비교용이며 미착용 프리셋의 최종 전투력을 제공하지 않는다. `user_context`도 이 한계를 바꾸지 않는다.
