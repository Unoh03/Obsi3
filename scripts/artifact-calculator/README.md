# 유니온 아티팩트 배치 계산기

`Run-ArtifactCalculator.cmd`를 더블클릭하고 **현재 아티팩트 레벨(1~60)**을 입력한다. 총 AP와 해금된 크리스탈 수를 자동 계산해 최적 배치를 표시한다. 결과를 본 뒤 다음 레벨을 입력하면 된다. 빈 입력은 직전 레벨 재사용, `q`는 종료다.

현재 배치를 유지하며 남은 AP만 쓰는 계산이 아니라 **해당 레벨의 총 AP로 전체 배치를 다시 계산**한다. 게임 내 초기화·옵션 변경을 실행하지 않으며, 실제 효과가 유지되려면 크리스탈이 활성 상태여야 한다.

## 계산 기준

아래 순서를 엄격히 적용한다. 뒤의 기준 때문에 앞의 최적값이 줄어들지 않는다.

1. 치확 **적용 Lv.10 필수**. 원시 합계가 10을 초과하는 배치도 허용한다.
2. 선택한 12종의 **실제 적용 레벨 총합 최대화**.
3. **최대 총합을 유지하면서 올스탯 Lv.1 이상을 확보할 수 있으면 확보**한다. 올스탯을 넣으면 최대 총합이 줄어드는 경우에는 Lv.0을 허용한다. 이 단계는 올스탯의 레벨 자체를 최대화하지 않는다.
4. 위 조건 안에서 `크뎀 → 공마 → 보공 → 데미지 → 방무 → 올스탯 → 드롭 → 메획 → 경험치 → 벞지 → 재사용` 순서로 효과 레벨을 비교한다.
5. 효과도 모두 같으면 **사용 AP 최소화**.
6. 완전 동점이면 배치 하나를 출력한다. 완전 동점인 크리스탈 배치는 실행마다 달라질 수 있다.

주황버섯의 **치확/크뎀/공마**, 뿔버섯의 **보공/데미지/방무** 옵션을 고정한다. 두 크리스탈의 레벨은 변경 가능하다. 나머지 크리스탈의 옵션·레벨은 자유롭게 계산한다. 치확과 조건부 올스탯 확보 규칙 외에는 최소 레벨을 강제하지 않는다.

최종 목표는 12종 각각 Lv.10, 실제 효과 레벨 총합 **120**이다. 최대 HP/MP·상태이상 내성·소환수 지속시간·파이널 어택은 대상에 포함하지 않는다. 피해량·직업별 효율·옵션 변경 비용·장기 성장 순서는 계산하지 않는다. AP와 옵션 변경 등에 사용하는 아티팩트 포인트는 별개다.

## 입력과 출력

- 레벨 `L`의 총 AP: `L + floor(L / 5)`.
- 크리스탈 수: `3 + floor(L / 10)`.
- 각 크리스탈은 Lv.1~5, 서로 다른 옵션 3개. 누적 AP 비용은 `0 / 1 / 3 / 5 / 8`.
- 같은 효과의 원시 합계는 해당 크리스탈들의 레벨 합, 적용 레벨은 `min(원시 합계, 10)`이다.
- `실제 효과 합 = 3 × 크리스탈 레벨 합 − 전체 초과분 합`으로 검산한다.

결과에는 레벨·총 AP·크리스탈 수, 크리스탈별 레벨/옵션/AP, 남은 AP, 크리스탈 레벨 합, 실제 효과 레벨 총합, 12종 전체의 원시/적용/초과분, 계산 시간을 표시한다. 6번째 이후 크리스탈은 번호로 표시한다. 결과 파일은 자동 저장하지 않는다.

명령행으로 한 번만 실행할 수도 있다. 먼저 이 폴더로 이동한다.

```powershell
.\.venv\Scripts\python.exe .\calculator.py --level 20
```

일반 사용자는 레벨만 입력한다. AP와 크리스탈 수를 직접 받는 `solve(budget, count)`는 내부 검증용이다. `Ctrl+C`는 계산을 중단하고 반복 입력으로 돌아간다. 입력 대기 중 `Ctrl+C` 또는 입력 종료(EOF)는 프로그램을 종료한다.

종료 코드는 단발 실행 기준으로 성공 `0`, 계산 오류 `1`, 조건 충족 불가능/잘못된 인자 `2`, 계산 중단·미완료 `130`이다. 반복 실행은 각 결과를 안내하고 다음 입력을 받는다. 계산이 끝나지 않은 해를 최적해나 불가능으로 표시하지 않는다.

## 정확성과 구현

Python 3.12와 OR-Tools CP-SAT을 사용한다. 총합 → 올스탯 확보 여부(0/1) → 효과별 우선순위 → AP 최소화의 **14단계 정수 최적화**를 수행하며, 각 단계가 `OPTIMAL`인 경우에만 값을 고정하고 다음 단계로 넘어간다. 총합을 먼저 고정하므로 올스탯 때문에 최대 총합이 감소하지 않는다. 앞 단계 해를 다음 단계의 탐색 힌트로 재사용한다.

자유 크리스탈은 같은 레벨끼리 묶는다. 레벨별 개수가 `c`일 때 효과별 배치 개수를 `0~c`로 제한하고 전체 옵션 수를 `3c`로 맞춘다. 이 조건은 각 크리스탈에 서로 다른 옵션 3개를 배치하는 것과 동등하다. 남은 배치 개수가 가장 큰 효과 3개씩 선택해 실제 크리스탈로 복원하며, 복원 뒤 별도 검산 함수로 모든 조건을 다시 확인한다. 크리스탈 자리만 바꾼 중복 탐색을 없애기 위한 표현이며 근사 계산이 아니다.

가능한 레벨 조합과 치확 초과분으로 총합의 안전한 상한을 계산한다. 총합·효과 최적값이 확정될 때마다 그 값을 만들 수 없는 레벨 조합만 제외한다. 크리스탈 레벨 합 자체를 우선 최적화하지 않는다.

## 실행 환경과 재설치

이 PC에는 전용 `.venv` 설치를 완료했다. 이후 실행에는 네트워크나 NEXON API key가 필요 없다. `.venv`는 Git에 포함하지 않는다.

현재 가상환경은 Codex가 제공한 Python 3.12.14를 기반으로 한다. 해당 런타임이 삭제·이동되면 설치된 다른 Python 3.12를 지정해 환경을 다시 준비해야 한다. 실행기는 PATH의 `python`/`pwsh` 별칭 대신 이 폴더의 가상환경을 직접 호출한다.

다음 명령은 **이 폴더에서** 실행한다. 다른 PC에서는 첫 줄을 실제 Python 3.12 실행 파일 경로로 바꾼다. 전역 Python 패키지는 변경하지 않는다.

```powershell
$artifactPython = Join-Path $env:USERPROFILE '.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $artifactPython -m venv --without-pip .venv
New-Item -ItemType Directory -Force .venv\tmp | Out-Null
$artifactOldTemp = $env:TEMP
$artifactOldTmp = $env:TMP
try {
    $env:TEMP = (Resolve-Path .venv\tmp).Path
    $env:TMP = $env:TEMP
    & .\.venv\Scripts\python.exe -m ensurepip --upgrade --default-pip
    if ($LASTEXITCODE -ne 0) { throw 'pip 준비 실패' }
    & .\.venv\Scripts\python.exe -m pip install --no-cache-dir -r requirements.txt
    if ($LASTEXITCODE -ne 0) { throw '패키지 설치 실패' }
} finally {
    $env:TEMP = $artifactOldTemp
    $env:TMP = $artifactOldTmp
}
```

## 검증 결과

2026-10-11 KST, 로컬 Python 3.12.14 / OR-Tools 9.15.6755에서 확인했다.

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

- 자동 테스트 17개 통과: 전체 60개 레벨 환산표, 3개 크리스탈의 모든 레벨/옵션 조합과 AP0~24 최적해 대조, 복원 조건, 우선순위, 초과분, 최소 AP, 오류·중단, 반복 입력, 다른 작업 폴더에서 `.cmd` 실행과 UTF-8 출력. Lv.23의 방무8·올스탯2와, 올스탯이 총합을 낮추는 조건을 주입했을 때 올스탯을 제외하는 처리도 검증한다.
- Lv.1~60 전체 실행: Lv.1~9는 현재 고정 조건에서 치확 10 확보 불가능, Lv.10~60은 각 단계 최적해 확정 및 배치 검산 통과. 조건부 올스탯 규칙 추가 전 버전과 비교해 모든 레벨의 최대 총합이 같으며, 가능한 모든 레벨에서 올스탯을 확보했다.
- 전체 레벨 실행에서 초기 Python/패키지 로딩을 제외한 계산 시간은 **0.4초 이내**였다. 실제 시간은 PC 부하와 실행마다 달라진다.

| 레벨 | AP / 크리스탈 | 실제 효과 합 | 사용 AP | 관측 계산 시간 |
|---:|---|---:|---:|---:|
| 20 | 24 / 5개 | 57 | 24 | 약 0.23초 |
| 21 | 25 / 5개 | 58 | 25 | 약 0.23초 |
| 23 | 27 / 5개 | 60 | 27 | 약 0.19초 |
| 30 | 36 / 6개 | 78 | 36 | 약 0.20초 |
| 40 | 48 / 7개 | 96 | 48 | 약 0.30초 |
| 50 | 60 / 8개 | 114 | 58 | 약 0.23초 |
| 60 | 72 / 9개 | 120 | 59 | 약 0.39초 |

Lv.21은 크리스탈 합이 20이어도 치확 원시 합계 12의 초과분을 제외해 실제 효과 합이 58이다. Lv.60은 12종을 모두 10으로 만드는 데 AP59가 필요하며 AP13을 남긴다. 과거 AP24 예시는 유효한 해로 검산했으나, 현재의 효과 우선순위에 따른 출력 배치는 과거 예시와 다를 수 있다.

Lv.23은 다음 배치로 **치확·크뎀·공마·보공·데미지 각각 10, 방무8, 올스탯2**, 효과 합 60을 만든다. AP는 `8+5+8+5+1=27`이다.

| 크리스탈 | 레벨 | 옵션 |
|---|---:|---|
| 주황버섯 | 5 | 치확 / 크뎀 / 공마 |
| 뿔버섯 | 4 | 보공 / 데미지 / 방무 |
| 슬라임 | 5 | 치확 / 크뎀 / 공마 |
| 스텀프 | 4 | 보공 / 데미지 / 방무 |
| 스톤골렘 | 2 | 보공 / 데미지 / 올스탯 |

Windows 탐색기의 실제 마우스 더블클릭과 게임 내 적용은 확인하지 않았다. 더블클릭이 호출하는 `.cmd`를 별도 작업 폴더에서 실행하는 경로는 테스트했다.

## 규칙 출처와 한계

- **1번류:** 이 도구의 테스트·실행 결과와 원래 아티팩트 노트의 AP24 배치 검산. 현재 게임 캐릭터의 AP·활성 상태를 조회한 결과는 아니다.
- **2번류:** [메이플스토리 공식 아티팩트 가이드](https://maplestory.nexon.com/Guide/N23GameInformation/Articles/408) — 해금 수, 세 옵션, 레벨별 소모 AP, 효과 Lv.10 상한과 활성 기간.
- **3번류:** [유니온 아티팩트 공개 성장표](https://d.namu.moe/w/유니온%20아티팩트) — Lv.1~60 누적 AP. 공식 가이드에 상세 지급량이 없어 이 표를 채택했으며, 게임 화면과 직접 대조하지 않았다.
- 엔진의 판정 의미는 [OR-Tools CP-SAT 공식 문서](https://developers.google.com/optimization/cp/cp_solver)를 따른다. 고정 버전의 [Windows Python 패키지](https://pypi.org/project/ortools/9.15.6755/)를 사용한다.

레벨·AP 규칙이 바뀌면 `artifact_engine.py`의 규칙과 테스트 기준표를 함께 갱신해야 한다. 기존 수집기·API 원본·아티팩트 노트는 이 계산기가 읽거나 수정하지 않는다.
