## 보안·비용·운영 주의

- 실습에는 고정된 가짜 데이터만 사용했고, 획득한 임시 Credential 값은 출력·저장하지 않았다.
- 전체 Alert JSON과 화면에는 Account, Bucket, IP, 임시 Access Key ID 등이 포함될 수 있으므로 외부 보고서에는 필요한 Field만 선별한다.
- Custom Rule은 Docker Named Volume에 있으므로 `docker compose down -v`를 실행하면 사라질 수 있다. 최종 재현 가능한 Host 원본이 필요하다.
- `daily-down` 완료를 확인했다. Daily Terraform State는 비었고 Tracked Residue와 Tagged Runtime은 없으며, Foundation ECR·GitHub Actions Role·Security Log S3만 의도대로 유지됐다.
- Post-destroy Evidence 8종을 수집했고, Manifest는 `C:\Users\Unoh\Documents\aws-topology-evidence\capital-one-20260813T082735Z-post-destroy\manifest.json`에 있다. `dvwa-application-dr`은 Event 0건으로 `Empty`였다.
- Docker Desktop 종료 여부는 아직 확인되지 않았다.
