# 8.19 멘토 노트 — 검증 보고서

## 결론

현재 감사 구조는 다음을 분리한다.

```text
불변 원본
→ 바이트 단위 무손실 보존

승인 교정 C01~C16
→ 최신 판단을 바꾸는 유일한 Overlay

네 개 파생 View
→ 읽기·학습·보고·발표용
→ 원본 전체의 무변형 분할본이라고 주장하지 않음
```

이 방식으로 **원문 소실과 조용한 교정은 기계적으로 방지**한다. 자유 재서술 문장의 절대적 의미 동일성은 주장하지 않고, 파생 View를 독립 정본으로 두지 않음으로써 그 위험을 정본 경계 밖으로 격리한다.

## 8. 보장 문구

현재 사용할 수 있는 가장 강한 문구:

> **분리 전 원본과 현재 SUPERSEDED 보존본은 동일 Git Blob이므로 바이트 단위로 완전히 같다. 최신 판단은 승인된 교정 C01~C16으로만 갱신하며, 네 개 재구성 문서는 파생 View로 관리한다. Manifest에 고정된 Blob이나 필수 교정 Anchor가 변경되면 자동 검증이 실패하므로, 이후의 조용한 Drift를 탐지할 수 있다.**

사용하지 않는 문구:

> `네 개 파생 View의 모든 문장은 원문과 의미가 100% 동일하다.`

그 문장을 증명하려 하지 않고, 불변 Source와 명시적 교정 Overlay를 정본으로 삼는 방식으로 문제를 제거한다.
