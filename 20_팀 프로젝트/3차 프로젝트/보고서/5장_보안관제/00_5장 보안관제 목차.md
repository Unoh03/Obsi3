# 5장 보안관제 보고서 목차

## 번호 체계

- `핵심 결과 요약`은 결론을 먼저 보여주는 페이지이며 절 번호를 붙이지 않는다.
- 보고서에 표시하는 절 번호는 `5.1`부터 `5.5`까지만 사용한다.
- 각 절 내부 제목에는 `5.4.1`, `5.4.2` 같은 번호를 붙이지 않는다.
- Capital One 시나리오는 여러 절을 연결하는 검증 사례이며 독립 절로 편성하지 않는다.

## 경계

- `low → impossible`은 자동 Source Patch가 아니라 DVWA에 사전 구현된 방어 프로필을 배포하는 고정·가역 Playbook이다.
- 실제 운영환경에서는 취약 코드 수정, 새 Image 배포, 탈취 자격증명 무효화와 Node·IAM 후속 대응이 별도로 필요하다.
- Rule `100110`과 Rule `100111`은 서로 다른 계층의 독립 증거이며 자동 상관분석 결과가 아니다.
