High ≠ 안전, Impossible ≠ Production 인증

High에서도 SQL 문자열 결합, Shell blacklist, 무제한 인증 시도가 남는다. Impossible은 해당 실습 취약점의 근본 원인을 줄인 예시지만 앱 전체의 현대 보안 기준을 보장하지 않는다.
