# 3차 프로젝트 목차

## 현재 상태

- 프로젝트: `퍼블릭 클라우드 기반 보안 운영`
- 수행기간: `2026-07-28 ~ 2026-08-28`
- 상태: 프로젝트 종료. 현재 이 MOC는 초기 계획이 아니라 최종 구현·보고서·Runtime 증거·회고로 가는 라우터다.
- 핵심 흐름: AWS·EKS의 애플리케이션·보안 로그 → Wazuh 분석·단계별 탐지 → Shuffle의 제한 조건 재검증 → 고정된 GitHub Actions / Argo CD 경로 → 격리·방어 수준 전환 → 실행·Git·Argo·Pod 상태 증거와 Reset.
- 팀 전체 결과와 장운호 개인 기여는 별도로 확인한다. 구현 파일의 존재만으로 Runtime 성공을 주장하지 않는다.

## 기록 경계

- 강사 원문, 팀 결정, 실제 실행 결과와 AI 해석을 구분한다.
- 팀 전체 성과와 개인 기여를 별도로 기록한다.
- 초기 계획·후보 평가는 최종 구현으로 간주하지 않는다.
- Access Key, Token, 비밀번호, kubeconfig 등 Secret은 Vault에 기록하지 않는다.
- AWS 생성·변경·삭제와 비용 검증은 실제 계정·명령 출력으로 확인한다.
