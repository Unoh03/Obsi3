# 중요 소비·강화 의사결정 프로토콜

> [!IMPORTANT]
> 이 문서는 메이플스토리에서 **비싸거나 희귀하거나 되돌리기 어려운 소비·강화·거래**를 판단할 때 사용하는 기준이다.
>
> **발동은 넓게, `갈!`은 좁게 적용한다.**
>
> AI가 한 세션에서 이 프로토콜을 처음 적용하는 경우, 일부 검색 결과만 읽지 말고 **이 문서를 처음부터 끝까지 전체 읽은 뒤 판단한다.**

---

# 1. 목적

다음과 같은 실수를 줄이는 것이 목적이다.

- 희귀 자원을 가치가 낮은 곳에 사용
- 고가 장비를 잘못 강화·판매·분해
- 더 좋은 대안이 있는데 성급하게 소비
- 장기 성장 계획을 깨는 단기 투자
- 최신 패치·이벤트·시세를 확인하지 않고 실행
- 확률형 강화의 위험을 과소평가
- 되돌리기 어려운 행동을 정보 부족 상태에서 실행
- 사용 기간이 짧은 장비에 과투자
- 사용자의 실제 가용 자산을 모른 채 손실을 감당 가능하다고 가정

단순히 **“비싸니까 하지 말자”**가 목적은 아니다.

충분히 검토한 결과 합리적인 선택이라면 그대로 진행할 수 있다.

# 2. 프로토콜 발동 판정

## 빠른 판정표

| 축 | 🟢 낮음 | 🟡 검토 필요 | 🔴 높음 |
|---|---|---|---|
| **가격 / 소비량** | 부담이 작음 | 체감 가능한 지출 | 큰 자산을 소비 |
| **희귀성** | 쉽게 재수급 | 시간/노력 필요 | 한정·희귀·수급 곤란 |
| **복구 가능성** | 쉽게 되돌림 | 비용을 들이면 복구 | 사실상 비가역 |
| **실패 위험** | 없음/미미 | 확률적 손실 | 큰 손실·파괴 가능 |
| **기회비용** | 다른 사용처가 중요하지 않음 | 경쟁 사용처 존재 | 더 중요한 사용처 존재 가능 |
| **사용 수명** | 장기간 사용 | 중기 사용 | 곧 교체·만료 예정 |
| **장기 계획 영향** | 없음 | 일부 영향 | 성장 계획 자체 변경 |
| **정보 확실성** | 규칙과 가치가 명확 | 일부 확인 필요 | 최신 검증 없이는 판단 곤란 |

## 발동 원칙

- 하나라도 🔴에 해당하면 **중요 의사결정 프로토콜 발동**
- 여러 개의 🟡이 겹치는 경우에도 발동 가능
- 확실하지 않으면 **프로토콜은 발동한다**
- 프로토콜 발동 자체가 `갈!`을 의미하지는 않는다

> **발동은 넓게, `갈!`은 좁게.**

# 3. 자동 발동 대상

아래 행동은 기본적으로 중요 의사결정 후보로 취급한다.

| 유형 | 예시 |
|---|---|
| **강화** | 스타포스, 주문서, 잠재능력, 에디셔널 잠재능력, 환생의 불꽃 |
| **장비 투자** | 고가 장비 구매, 교체, 직작 |
| **장비 처분** | 판매, 교환, 분해, 버리기 |
| **희귀 자원 사용** | 한정 강화권, 이벤트 보상, 수급 제한 재화 |
| **대규모 소비** | 많은 메소·메이플포인트 사용 |
| **확률형 투자** | 실패 가능성이 있는 강화·재설정 |
| **비가역 선택** | 되돌릴 수 없거나 복구 비용이 매우 큰 행동 |
| **기간제 투자** | 곧 만료되거나 교체 예정인 장비에 대한 투자 |
| **장기 계획 변경** | 기존 성장·장비·재화 계획에 영향을 주는 투자 |

# 4. 실행 직전 문맥

사용자의 질문이 실제 실행에 가까울수록 검토 우선순위를 높인다.

| 사용자 표현 | 처리 |
|---|---|
| `이게 뭐야?` | 일반 정보 |
| `이거 좋은 거야?` | 기본 평가 |
| `어디 쓰는 게 좋아?` | 🟡 사용처 검토 |
| `여기 써도 돼?` | 중요 검토 |
| `박을까?` | 중요 검토 |
| `살까?` | 중요 검토 |
| `팔까?` | 중요 검토 |
| `분해해도 돼?` | 중요 검토 |
| `지금 누를까?` | **즉시 실행 전 검토** |
| `지금 창 띄워놨어` / `누르기 직전` | **위험 요소 우선 확인** |

> 실행 직전이라고 판단되면 단순한 정보 제공보다 **손실 방지 검토를 우선한다.**

| 5 | **손실** | 실패하거나 소비하면 무엇을 잃는가? |

| 11 | **장기 계획** | 기존 성장·장비·재화 계획과 충돌하지 않는가? |
| 12 | **최신성** | 패치·이벤트·가격·강화 규칙이 최신인가? |
| 13 | **근거 충분성** | 지금 가진 정보만으로 실행을 권할 수 있는가? |

# 6. 현재 상태와 정보 출처

정보의 출처는 단순한 고정 순위보다 **질문과의 직접 관련성, 최신성, 검증 가능성**을 함께 본다.

## 일반적인 우선 기준

1. **사용자가 현재 화면을 보고 직접 확인한 정확한 정보 또는 최신 스크린샷**
2. **가장 최신의 검증 가능한 `ai-context` / Maple API 자료**
3. **같은 세션에서 이미 확정한 최신 정보**
4. **사용자의 근사치·기억 기반 보고**
5. **과거 메모리 및 이전 대화**

다만 다음과 같은 정보는 별도로 취급한다.

- 게임 규칙
- 이벤트 기간
- 강화 확률
- 사용 조건
- 교환 가능 여부
- 파괴 및 복구 규칙

이런 항목은 **공식 최신 자료가 캐릭터 상태 자료보다 우선**한다.

## 근사 표현 처리

사용자가 다음과 같이 말한 경우 정확한 값으로 고정하지 않는다.

- `대략`
- `한 3000쯤`
- `아마`
- `17성이었던 것 같은데`
- `이거였나?`

정확한 최신 자료와 사용자의 근사 표현이 충돌하면 **근사 표현을 우선하지 않는다.**

현재 상태 파일은 수집 시점의 스냅샷이므로 실시간 상태라고 가정하지 않는다.

# 7. 장기 계획 충돌 검사

개별 행동만 보면 효율적이어도 장기 계획에서는 손해일 수 있다.

따라서 다음을 별도로 확인한다.

| 질문 | 예시 |
|---|---|
| 이 재화를 다른 장비에 쓰기로 한 계획이 있는가? | 강화권 예약 |
| 곧 교체할 장비에 과투자하는 것은 아닌가? | 임시 장비 직작 |
| 다음 성장 단계에서 가치가 급격히 떨어지는가? | 장비 세트 전환 |
| 예정된 이벤트가 같은 투자를 더 싸게 만들어주는가? | 스타포스/큐브 이벤트 |
| 지금 소비하면 더 중요한 목표를 늦추는가? | 심볼, HEXA, 장비 구매 등 |

장기 계획을 명확히 모르는 경우 **임의로 계획을 만들어내지 않는다.**

# 8. 사용 수명 검사

장비나 자원이 얼마나 오래 가치 있게 쓰이는지를 독립적으로 확인한다.

특히 다음은 우선 확인한다.

- 기간제 장비
- 이벤트 장비
- 임시 장비
- 곧 교체 예정인 장비
- 상위 장비 전환이 예정된 부위
- 성장 단계상 수명이 짧은 아이템

## 핵심 질문

- 이 장비는 언제까지 사용할 예정인가?
- 만료일이 있는가?
- 다음 장비 교체 시점은 언제인가?
- 지금 투자한 비용을 회수할 만큼 충분히 오래 사용하는가?
- 단기 성장을 위해 투자할 가치가 있는가?

장비 자체가 좋은지와 **지금 그 장비에 투자하는 것이 좋은지**는 별개의 판단으로 취급한다.

# 10. 최종 판정

| 판정 | 의미 | 대응 |
|---|---|---|
| 🟢 **진행 가능** | 특별한 위험 요소 없음 | 근거 설명 후 진행 가능 |
| 🟡 **확인 후 진행** | 일부 조건 확인 필요 | 필요한 확인 사항 제시 |
| 🟠 **재검토 권장** | 효율·기회비용 문제가 큼 | 대안 비교 후 결정 |
| 🔴 **갈!** | 추가 검증 전에 실행을 멈춰야 할 위험 발견 | 즉시 경고 후 위험 설명 |

## 🟠과 🔴의 경계

### 🟠 재검토 권장

다음과 같은 상황이다.

- 더 효율적인 선택이 존재함
- 기회비용이 큼
- 타이밍이 좋지 않음
- 장기적으로 덜 좋은 선택일 가능성이 있음

그러나 **지금 실행해도 치명적인 실수나 큰 비가역 손실로 직결되지는 않는 경우**다.

### 🔴 `갈!`

다음과 같은 상황이다.

- 지금 실행하면 큰 손실이 발생할 가능성이 높음
- 되돌리기 어려운 실수가 될 수 있음
- 핵심 정보가 빠진 상태에서 실행하려 함
- 잘못된 전제나 오래된 정보에 기반함
- 장기 계획을 크게 훼손함
- 더 중요한 사용처가 명확한데 회수 어려운 자원을 소비하려 함

즉 **추가 검증 전에 실행하면 안 되는 상태**다.

# 11. `갈!` 발동 조건

다음 중 하나 이상이 **의미 있는 수준으로 확인**되면 `갈!`을 사용한다.

| 발동 사유 | 설명 |
|---|---|
| **큰 손실 위험** | 실패 시 상당한 재화·아이템 가치 손실 |
| **비가역 실수** | 되돌릴 수 없거나 복구가 매우 어려움 |
| **명확한 낭비** | 같은 자원의 가치가 훨씬 높은 사용처가 존재 |
| **잘못된 대상** | 사용하려는 아이템·장비 자체가 적절하지 않음 |
| **장기 계획 충돌** | 기존의 더 중요한 성장 계획을 훼손 |
| **중대한 정보 부족** | 필요한 핵심 정보를 모른 채 실행하려 함 |
| **잘못된 전제** | 사실과 다른 전제를 기반으로 실행하려 함 |
| **최신성 문제** | 오래된 규칙·시세·공략을 근거로 큰 소비를 하려 함 |
| **사용 수명 문제** | 곧 교체·만료될 대상에 과도한 자원을 투자하려 함 |

## 확률형 강화 예외

단순히 실패 확률이나 파괴 확률이 존재한다는 이유만으로 `갈!`을 발동하지 않는다.

확률형 강화에서는 다음을 함께 판단한다.

- 현재 목표
- 현재 자산
- 대체품 확보 가능성
- 이벤트 여부
- 복구 가능성
- 목표 강화 단계
- 기대 비용
- 사용자가 감당 가능한 손실 범위

즉:

> `22성은 파괴될 수 있다`
> → 위험 검토 대상

> `곧 강화 이벤트가 있는데 지금 노이벤트로 고가 장비 22성을 누르려 한다`
> → 상황에 따라 `갈!`

처럼 구분한다.

# 12. `갈!`의 의미

> [!DANGER]
> **갈!**

`갈!`은 **최종 반대 판정이 아니다.**

**실행을 일시 정지시키는 인터럽트**다.

즉:

> 지금 실행하지 말고 위험 요소를 먼저 확인하거나 재검토해야 한다.

필요한 검증이 끝나면 `갈!` 상태는 해제될 수 있으며 최종 판정은 다음 중 하나로 바뀔 수 있다.

- 🟢 진행 가능
- 🟡 확인 후 진행
- 🟠 재검토 권장

`갈!`을 사용했으면 반드시 다음을 설명한다.

1. 무엇이 위험한가
2. 어떤 손실이 발생할 수 있는가
3. 무엇을 먼저 확인해야 하는가
4. 가능하면 더 안전하거나 효율적인 대안은 무엇인가

---

# 13. `갈!`을 사용하지 않는 경우

다음 상황에서는 단순히 비싸거나 위험 요소가 존재한다는 이유만으로 경고하지 않는다.

- 가격은 높지만 사용처가 명확하게 적절함
- 실패 위험을 사용자가 충분히 이해하고 있음
- 장기 계획과 일치함
- 다른 현실적인 대안이 없음
- 지금 사용하는 것이 시기적으로 합리적임
- 필요한 최신 정보가 충분히 확인됨
- 위험 대비 기대 이득이 현재 목표에 맞음
- 자산 대비 손실 규모가 실제로 감당 가능한 수준임

다만:

> 사용자의 현재 가용 자산이 확인되지 않았다면 **감당 가능한 손실 규모를 임의로 추정하지 않는다.**

즉 **비싼 행동 = 위험한 행동**으로 자동 판단하지 않는다.

---

# 14. 정보 부족 처리

판단에 필요한 핵심 정보가 부족하면 추측으로 실행을 권하지 않는다.

예:

> 현재 아이템의 정확한 옵션을 모르면 이 강화권을 여기에 쓰는 게 맞는지 확정할 수 없음.

필요한 경우 다음을 확인한다.

- 스크린샷
- 아이템 옵션
- 보유 재화
- 현재 장비 구성
- 최신 API 상태
- 시세
- 이벤트 기간
- 강화 규칙
- 장비 만료일
- 장비 교체 예정 시점

중요 소비에서는 **“잘 모르겠지만 해도 될 듯”** 식으로 결론내리지 않는다.

# 16. AI 세션 운용 규칙

> [!NOTE]
> 이 섹션은 AI가 이 문서를 사용할 때의 규칙이다.

## 세션 최초 발동

한 대화 세션에서 이 프로토콜이 처음 발동한 경우:

1. 이 문서를 **처음부터 끝까지 전체 읽는다.**
2. 검색 결과나 일부 문단만으로 정책을 파악했다고 가정하지 않는다.
3. 전체 판정 구조·예외·`갈!` 조건·유형별 추가 체크까지 인지한다.
4. 문서 전체를 읽은 뒤 실제 질문을 판단한다.

## 같은 세션의 후속 질문

이미 전체 문서를 읽었다면 매 질문마다 전체 재독은 필요하지 않다.

다만 다음 경우 다시 확인한다.

- 문서가 수정됨
- 사용자가 문서 수정 사실을 알림
- 새로운 유형의 의사결정이 등장
- 판정 기준이 모호함
- 큰 손실 가능성이 있음
- `갈!` 발동 여부가 애매함
- 이전에 읽은 세부 규칙이 불확실함

## 문서 접근 실패

이 문서를 실제로 읽지 못했다면:

- 읽었다고 주장하지 않는다.
- 메모리에 있는 기본 안전 규칙까지만 적용한다.
- 상세 기준을 확인하지 못한 상태임을 판단에 반영한다.

# 18. 핵심 원칙 요약

| 원칙 | 의미 |
|---|---|
| **발동은 넓게** | 위험 가능성이 있으면 검토 |
| **`갈!`은 좁게** | 실제 위험이 확인됐을 때만 강하게 경고 |
| **`갈!`은 인터럽트** | 영구 금지가 아니라 검증 전 일시 정지 |
| **현재 상태 우선** | 오래된 장비·재화 상태로 판단하지 않음 |
| **근사치는 근사치로** | 사용자의 기억 기반 수치를 확정값으로 만들지 않음 |
| **비가역성 중시** | 되돌리기 어려울수록 더 신중하게 |
| **기회비용 확인** | 더 좋은 사용처가 있는지 확인 |
| **사용 수명 확인** | 곧 교체·만료될 대상에 과투자하지 않음 |
| **장기 계획 연결** | 개별 효율보다 전체 성장 계획까지 확인 |
| **최신 검증** | 큰 소비일수록 최신 공식 정보 확인 |
| **자산 추정 금지** | 가용 자산을 모르면 감당 가능 여부를 추정하지 않음 |
| **정보 부족 시 정지** | 핵심 정보가 없으면 실행 권고하지 않음 |
| **비싸다고 자동 경고하지 않음** | 합리적인 고가 투자는 허용 |
| **확률이 있다고 자동 경고하지 않음** | 위험이 현재 상황에 부적절한지 판단 |
