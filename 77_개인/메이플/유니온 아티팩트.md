# 유니온 아티팩트

## 핵심 목표

- 크리스탈 **총 레벨 합을 가능한 한 높게 유지**한다.
- 다만 매 레벨마다 1레벨 차이를 메우기 위해 반복 초기화하지 않는다.
- 크리티컬 확률은 아티팩트에서 **Lv.10으로 고정**해 하이퍼/유니온/링크의 치확 변동을 줄인다.
- 최종적으로는 **크리스탈 이름/해금 순서와 역할을 고정**해 가독성을 높인다.
- 우노03은 **펫 자동 버프로 전투 중 크리티컬 확률 +11%**가 추가된다는 점을 치확 계산에 포함한다.

## 공식 규칙 메모

- 크리스탈은 Lv.1부터 Lv.5까지 성장한다.
- 누적 AP 비용:
  - Lv.1 = 0
  - Lv.2 = 1
  - Lv.3 = 3
  - Lv.4 = 5
  - Lv.5 = 8
- 각 크리스탈은 서로 다른 옵션 3개를 가진다.
- 같은 옵션은 여러 크리스탈에서 합산되지만 **실제 적용은 Lv.10이 상한**이다.
- 아티팩트 Lv.20의 보유 AP는 24, Lv.21은 25.
- 공식 가이드: https://maplestory.nexon.com/Guide/N23GameInformation/Articles/408

## 2026-10-02 결정 사항

- 사용자가 **AP 초기화를 이미 실행했다.**
- 이번 초기화 이후에는 가독성과 장기 고정 구조를 우선해 세팅한다.
- 이후에는 **이론상 총레벨 1을 더 얻기 위해 매 레벨 재초기화하지 않는다.**
- 옵션 변경 역시 최종 구조에 가까워지는 방향으로만 수행한다.

## 최종 크리스탈 역할 고정

### 1쌍 — 기본 공격 축

- **주황버섯** → 크리티컬 확률 / 크리티컬 데미지 / 공격력·마력
- **슬라임** → 크리티컬 확률 / 크리티컬 데미지 / 공격력·마력

최종 목표:
- 치확 Lv.10
- 크뎀 Lv.10
- 공마 Lv.10

### 2쌍 — 보스 축

- **뿔버섯** → 보스 데미지 / 데미지 / 방어율 무시
- **스텀프** → 보스 데미지 / 데미지 / 방어율 무시

최종 목표:
- 보공 Lv.10
- 데미지 Lv.10
- 방무 Lv.10

### 3쌍 — 사냥/재화 축

해금 순서상 다음 두 크리스탈:
- **스톤골렘**
- **그 다음 해금 크리스탈**

옵션:
- 경험치 / 아이템 드롭률 / 메소 획득량

최종 목표:
- 경험치 Lv.10
- 드롭 Lv.10
- 메획 Lv.10

### 4쌍 — 공용 보조 축

그 다음 해금되는 두 크리스탈:

옵션:
- 올스탯 / 버프 지속시간 / 재사용 대기시간 미적용

최종 목표:
- 올스탯 Lv.10
- 벞지 Lv.10
- 재사용 Lv.10

은월 단독 기준으로 벞지·재사용의 우선도가 아주 높지 않을 수 있으나, 카이저 등 월드 내 다른 캐릭터까지 고려한 공용 구조로 둔다.

### 마지막 1개

9번째 크리스탈은 **추후 결정**한다.

- 당시 남아 있는 옵션
- 우노03/카이저/레테 등 실제 주력·부캐 구성
- 부족한 계정 공용 능력치

를 보고 정한다.

## Lv.20 당장 세팅 — 총레벨 최대 + 치확 Lv.10

Lv.20 AP 24에서 5개 크리스탈의 **최대 총 레벨 합은 19**다.

현재는 최종 고정 구조 중 **주황버섯과 뿔버섯의 역할을 반드시 유지**하면서, 나머지 3개를 임시로 활용해 치확 Lv.10과 총레벨 19를 동시에 맞춘다.

추천 레벨 분배:

**뿔버섯 5 / 주황버섯 4 / 슬라임 4 / 스텀프 3 / 스톤골렘 3**

AP 사용량:
- 8 + 5 + 5 + 3 + 3 = 24
- 총 크리스탈 레벨 합 = 19

### 현재용 옵션 배치

| 크리스탈 | 레벨 | 옵션 | 비고 |
|---|---:|---|---|
| 주황버섯 | 4 | **치확 / 크뎀 / 공마** | 최종 고정 |
| 뿔버섯 | 5 | **보공 / 데미지 / 방무** | 최종 고정 |
| 슬라임 | 4 | 크뎀 / 공마 / 올스탯 | 임시 |
| 스텀프 | 3 | 치확 / 보공 / 데미지 | 임시 |
| 스톤골렘 | 3 | 치확 / 방무 / 올스탯 | 임시 |

이 배치의 실제 효과 레벨:

| 옵션 | 효과 레벨 |
|---|---:|
| 치확 | **10** |
| 크뎀 | 8 |
| 공마 | 8 |
| 보공 | 8 |
| 데미지 | 8 |
| 방무 | 8 |
| 올스탯 | 7 |

총 크리스탈 레벨 19를 전부 사용하면서 치확을 정확히 Lv.10으로 맞춘다.

## 이후 성장 원칙

- Lv.21에서 이론상 `4/4/4/4/4`로 총레벨 20이 가능하더라도, **그 1레벨 때문에 다시 전면 초기화하지 않는다.**
- 자연스럽게 AP가 쌓여 현재 크리스탈을 올릴 수 있을 때 올린다.
- 새 크리스탈이 해금되면 위의 **최종 역할 고정표 순서**에 따라 배정한다.
- 슬라임과 스텀프는 장기적으로 각각 최종 짝의 옵션으로 복귀시킨다.
- 스톤골렘은 장기적으로 **경험치 / 드롭 / 메획** 축으로 전환한다.
- 아티팩트 치확 Lv.10을 최종 기준점으로 유지한다.

## 치확 고정 이후 할 일

아티팩트 치확 Lv.10을 확정한 뒤:

1. 실제 전투 중 펫 자동버프 포함 크확 100% 확인
2. 하이퍼 치확 재조정
3. 유니온 치확 재조정
4. 필요하면 치확 링크도 재조정
5. 이후 아티팩트 레벨업 때 치확 기준점은 되도록 흔들지 않는다.

> 핵심 의도: 아티팩트에서 치확을 고정값으로 확보해, 하이퍼/유니온/링크의 치확을 매번 다시 맞추는 번거로움을 줄인다.
