# 유니온 아티팩트

## 핵심 목표

- 크리스탈 **총 레벨 합을 가능한 최대로 유지**한다.
- 크리티컬 확률은 아티팩트에서 **Lv.10으로 고정**해 하이퍼/유니온/링크의 치확 변동을 줄인다.
- 단기 배치는 현재 레벨에서의 AP 효율을 우선하고, 장기적으로는 보기 쉬운 2개 단위 묶음으로 정리한다.
- 우노03은 **펫 자동 버프로 전투 중 크리티컬 확률 +11%**가 추가된다는 점을 치확 계산에 포함한다.

## 공식 규칙 메모

- 크리스탈은 Lv.1부터 Lv.5까지 성장한다.
- 누적 AP 비용:
  - Lv.1 = 0
  - Lv.2 = 1
  - Lv.3 = 3
  - Lv.4 = 5
  - Lv.5 = 8
- 각 크리스탈은 서로 다른 옵션 3개를 가진다.
- 같은 옵션은 여러 크리스탈에서 합산되지만 **실제 적용은 Lv.10이 상한**이다.
- 아티팩트 Lv.20의 보유 AP는 24, Lv.21은 25.
- 공식 가이드: https://maplestory.nexon.com/Guide/N23GameInformation/Articles/408

## Lv.20 즉시 재배치안 — 총 레벨 최대 + 치확 Lv.10

Lv.20 AP 24에서 5개 크리스탈의 **최대 총 레벨 합은 19**다.

추천 레벨 분배:

**5 / 4 / 4 / 3 / 3**

AP 사용량:
- 8 + 5 + 5 + 3 + 3 = 24
- 총 크리스탈 레벨 합 = 19

치확은 **4 + 3 + 3 = 정확히 Lv.10**이 되도록 세 크리스탈에 배치한다.

### 구체적인 옵션 예시

| 크리스탈 | 레벨 | 옵션 |
|---|---:|---|
| 1 | 5 | 보공 / 데미지 / 방무 |
| 2 | 4 | 치확 / 크뎀 / 공마 |
| 3 | 4 | 크뎀 / 공마 / 올스탯 |
| 4 | 3 | 치확 / 보공 / 데미지 |
| 5 | 3 | 치확 / 방무 / 올스탯 |

이 배치의 실제 효과 레벨:

| 옵션 | 효과 레벨 |
|---|---:|
| 치확 | **10** |
| 크뎀 | 8 |
| 공마 | 8 |
| 보공 | 8 |
| 데미지 | 8 |
| 방무 | 8 |
| 올스탯 | 7 |

총 크리스탈 레벨 19를 전부 사용하면서, 치확 상한 초과 낭비 없이 Lv.10을 맞춘다.

## Lv.21 메모

Lv.21은 AP 25.

이때 총 레벨 합 최대는 **20**이며, 가능한 최대 배치는:

**4 / 4 / 4 / 4 / 4**

다만 치확 Lv.10을 만들려면 세 크리스탈에 치확을 넣어 4+4+4=12가 되므로, 실제 적용은 10에서 잘리고 치확 쪽 2레벨은 효과 상한 때문에 낭비된다.

따라서 이후에는:
- **총 크리스탈 레벨 최대화**
- **실제 옵션 효과 총합 최대화**
- **가독성/장기 묶음 유지**

세 기준 중 무엇을 우선할지 보고 재조정한다.

## 장기 종결 구조 초안

사용자가 선호하는 가독성 기준:

- **치확 / 크뎀 / 공마 ×2**
- **보공 / 데미지 / 방무 ×2**
- **경험치 / 드롭 / 메획 ×2**
- **올스탯 / 벞지 / 재사용 ×2**
- **마지막 1개 ×1: 추후 결정**

마지막 1개는 계정 내 주력/부캐 구성과 실제 필요 옵션을 보고 정한다.

은월 단독 기준으로는 벞지·재사용 우선도가 아주 높지 않을 수 있지만, 카이저 등 다른 캐릭터까지 고려하면 계정 공용 옵션으로 가치가 생길 수 있다.

## 치확 고정 이후 할 일

아티팩트 치확 Lv.10을 확정한 뒤:

1. 실제 전투 중 펫 자동버프 포함 크확 100% 확인
2. 하이퍼 치확 재조정
3. 유니온 치확 재조정
4. 필요하면 치확 링크도 재조정
5. 이후 아티팩트 레벨업 때 치확 기준점은 되도록 흔들지 않는다.

> 핵심 의도: 아티팩트에서 치확을 고정값으로 확보해, 하이퍼/유니온/링크의 치확을 매번 다시 맞추는 번거로움을 줄인다.
