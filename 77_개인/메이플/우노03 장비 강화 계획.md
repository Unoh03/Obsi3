### 아르고 주화 충돌 규칙

| 상황 | 처리 |
|---|---|
| 페어리 하트에 주문서 10장이 전부 필요함 | 위 기본안 유지 |
| 하트에 필요한 주문서가 10장 미만 | 남는 주화를 이벤트 링 골드 큐브에 추가 |
| 어웨이크 링에서 드/메 유효옵이 빨리 뜸 | 남은 골드 큐브를 펄스 링으로 이동 |
| 펄스 링 전투 잠재가 빨리 완성됨 | 남은 골드 큐브를 어웨이크 드메에 사용 |
| 아르고 상점에서 다른 품목이 급해짐 | **골드 큐브 수량부터 줄이고**, 레전서 2장은 최대한 유지 |

> 이벤트 링 골드 큐브는 **메이플ID당 총 100개**다.  
> 펄스 링 100개 + 어웨이크 링 100개가 아니다.

## 5. 장비별 최종 역할

| 장비 | 역할 | 투자 상태 | 계획 |
|---|---|---|---|
| **루컨마** | 장기 눈장식 | 미보유 | 9/30까지 확보 가능하면 일반 카르마 레전서 |
| **블랙빈 마크** | 임시 눈장식 | 현역 | 최소 투자, 루컨마로 교체 |
| **트와일라이트 마크** | 얼굴장식 | 유니크 STR 15%급 | 현재 유지, 레전서 사용 안 함 |
| **여명의 가엔링** | 장기 전투 반지 | 현역 | 루컨마 실패 시 일반 카르마 레전서 |
| **글로리온 링 : 슈프림** | 전투 반지 | 레전 STR 21% | 그대로 유지 |
| **테네브리스 원정대 반지** | 임시 전투 반지 | 현역 | 추가 투자 중단 → 펄스 링으로 교체 |
| **어센던트 펄스 링** | 장기 전투 반지 | 육성 중 | 아르고 레전서 + 골드큐 + 스타포스 |
| **어웨이크 링** | 드메 전용 반지 | 전환 예정 | 아르고 레전서 + 골드큐로 드/메 |
| **미트라의 분노 : 해적** | 장기 엠블렘 | 본잠 레전 / **에디 유니크 완료, STR +6% 유효 1줄** | 이후 화에큐로 공% 중심 개선 |
| **에스텔라 이어링** | 장기 후보 | **브론즈 에디셔널 큐브 43개 사용 완료(2026-09-19), 전투력 소폭 상승** | 이후 핵심 장비 작업 종료 후 잔여 큐브 |
| **데이브레이크 펜던트** | 장기 후보 | 에디 개선 여지 | 잔여 화에큐 |

## 8. 절대 중복 사용 금지

| 재화 | 금지 사항 |
|---|---|
| 일반 카르마 레전서 | 어웨이크 링에 사용하지 않음 |
| 일반 카르마 레전서 | 루컨마와 가엔링 양쪽에 동시에 예약하지 않음 |
| 카르마 에디 유니크서 | **미트라에 사용 완료(2026-09-19)**. 추가 예약 없음 |
| 퍼스널 화에큐 | 미트라 작업 전 에스텔라/데브펜에 대량 사용하지 않음 |
| 아르고 골드 큐브 | 반지마다 100개라고 착각하지 않음 |
| 펄스 인핸서 | 30회 17성권을 기다리면서 0→17에 대량 소모하지 않음 |
| 테네브리스 링 | 펄스 교체 예정이므로 추가 투자하지 않음 |
| 도전자 장비 | 기간제 장비이므로 장기 강화재 사용하지 않음 |

## 현재 한 줄 요약

**루컨마/가엔링은 일반 카르마 레전서 하나를 공유한다. 미트라는 에디 유니크 적용을 완료했고 다음 단계는 화에큐다. 펄스·어웨이크는 아르고 이벤트링 재화, 페어리 하트는 출석 유잠+아르고 하트 주문서로 분리한다.**
