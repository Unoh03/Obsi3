### 10/9 API 수집 *이후* 가엔링 블랙 큐브 결과 및 다음 순서 (최신 사용자 직접 보고)

> **중요 정정: 사용자가 마지막 BEFORE/AFTER 결과 화면에서 선택한 것은 BEFORE(전자)이다.** 직전 2개 커밋에 기재한 ‘AFTER DEX 24% 선택 확정’은 잘못 읽은 내용이며 **폐기**한다. DEX 24%는 버린 옵션이다.

- **여명의 가디언 엔젤 링 실제 확정 결과:** **17성 / 윗잠 레전드리 ‘모든 스킬의 MP 소모 -15% / 올스탯 +6% / STR +9%’**. 은월 기준 유효 STR **15% 상당** (올스탯 6% + STR 9%). 이전 스냅샷보다 등급이 유니크→레전드리로 상승했다. 에디 에픽 STR4% + STR2%는 19:08 API 기준이며 이후 변경 보고 없음.
- **경매장 검색 상황:** 사용자가 18성 가엔링 매물 표시가 약 20~30억, 17성 비교 매물 없음이라고 보고했다. 이 정보만으로 현재 가엔링 매각 이익을 계산하지 않는다. **현재 반지는 사용·보존하며 ‘DEX24 매각 후 다시 구매’ 분기를 종료**한다.
- **블랙 큐브 기본 우선순위:** 가엔링은 **STR15% 상당을 이미 달성**했으므로 무조건 ‘복구 1순위’가 아니다. **에스텔라 이어링**(유니크 STR12%, 15% 상당 목표)을 우선 검토하고, **가엔링**은 레전드리 15→21% 이상으로 올리고 싶을 때 선택하는 고점 작업이다. 가엔링을 레전 등급이라고 해서 반드시 34회 블큐20개를 전부 몰아주는 것은 아님.
- **데이브레이크 펜던트:** 17성 유니크 STR9% + STR6% = STR15%, 에디 공10으로 **현재 저점 기준 충족**. 에스텔라/가엔링보다 뒤에 두고 레전 등업 도전은 나중에 검토한다.
- **출석 34회 블큐20개:** 아직 미수령. 수령 시 **에스텔라 유니크 12→15%와 가엔링 레전 15→21% 중 실제 기대 효율을 재평가**해 분배. 큐브 구매 완료나 잔량을 지금 확정하지 않음.
- **선택 원칙:** 블랙 큐브는 매회 BEFORE/AFTER에서 은월 유효 옵션을 비교한다. 최종 선택 전의 스크린샷은 적용 완료가 아니며, 사용자가 ‘전자(BEFORE)’라고 말했으면 BEFORE를 채택한 것으로 기록한다.
- **메멘토 실버 큐브:** 레전 가엔링에 사용 불가. **에스텔라 유니크**나 새 영구 장비 유니크 이하 옵션 개선용.
- **미트라:** 일반 블큐가 아닌 화이트 에디셔널 큐브 작업 대상. **HEXA는 사용자가 환산으로 자체 관리 중이므로 이 블큐 계획의 고려대상에서 제외**한다.
