## 3. 아르고 주화 예산

정찰 40회 완료 시 최대 **40,000주화**. 현재 잔액은 미확인이다. 두 반지는 이미 보유하므로 **반지 선택권 구매 비용은 0**이다.

| 대기 | 카르마 스페셜 하트 공격력 주문서 | 10 | 2,000 | **20,000** | 페어리 하트 |
| 대기 | 이벤트 링 전용 골드 큐브 | 80 | 150 | **12,000** | 펄스 + 어웨이크 |
|  | **합계** |  |  | **40,000** |  |

### 아르고 주화 충돌 규칙

| 상황 | 처리 |
|---|---|
| 페어리 하트에 주문서 10장이 전부 필요함 | 위 기본안 유지 |
| 하트에 필요한 주문서가 10장 미만 | 큐브는 총 100개 한도까지 추가. 기본안 대비 추가 20개에 최대 3,000주화, 그 이상 잔여는 보류 |
| 어웨이크 링에서 드/메 유효옵이 빨리 뜸 | 남은 골드 큐브를 펄스 링으로 이동 |
| 펄스 링 전투 잠재가 빨리 완성됨 | 남은 골드 큐브를 어웨이크 드메에 사용 |
| 아르고 상점에서 다른 품목이 급해짐 | **골드 큐브 수량부터 줄이고**, 레전서 2장은 최대한 유지 |

> 이벤트 링 골드 큐브는 **메이플ID당 총 100개**다.  
> 펄스 링 100개 + 어웨이크 링 100개가 아니다.

공식 상점 한도는 **메이플ID 공유**다. 이벤트 링 레전서는 3장(장당 4,000), 골드 큐브 100개(개당 150), 하트 주문서 선택권 10개(개당 2,000)다. 펄스·어웨이크는 레전서와 골드 큐브의 사용 대상에 모두 포함된다. [공식 상점 표·툴팁](https://maplestory.nexon.com/News/Event/Ongoing/1382)

하트 주문서는 **선택권에서 공격력 주문서를 선택**한다. 계획의 10장은 9/19 잔여 횟수 기준이며, 다른 작·황금망치 등으로 잔여 횟수가 바뀌면 다시 계산한다. 추가 슬롯이 생겨도 상점 한도가 늘어나는 것은 아니다.

**큐브 배분 제안(고정 비율 아님):** 사냥용 드메가 우선이면 어웨이크의 필요한 드롭/메획 한 줄을 먼저 확보하고 남은 큐브를 펄스에 쓴다. 보스 성능이 더 급하면 순서를 바꾼다. 펄스는 남은 인핸서로 잠재를 보충할 수 있지만, 어웨이크에는 그 수단이 없다. 목표 옵션이 나오면 멈추며 80개로 두 반지가 완성된다고 보장하지 않는다.
