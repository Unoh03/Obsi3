# 카이저 키세팅

> 최초 작성: 2026-09-25 / 키 재설계: 2026-10-23 / 극딜 시퀀스 순서 확정: 2026-10-24
>
> 목적: 은월에서 익숙한 키 역할을 최대한 유지하면서, 2026-09-17 본섭 1.2.419 이후 카이저 운용에 맞춘 보스용 키세팅을 고정한다.
>
> **설정 정책:** 사용자가 2026-10-23~24 대화에서 확정한 **장래의 키 배치 및 극딜 시퀀스 설계안**을 우선 기록한다. 현재 카이저를 육성해 실제 게임에 적용한 상태는 아니다. `2`에 등록할 9종과 **서버렉 활용을 목표로 한 순서**는 사용자가 선택해 확정했다. 단, 리레 4레벨에서 실측 검증된 최적해는 아니다.
>
> **주의:** 실제 보스에서 손에 안 맞는 부분은 변경 가능하다. 오리진/일반 바인드의 세부 순서는 보스 및 파티 빌드에 따라 달라질 수 있으므로 키 위치와 극딜 순서를 분리한다.

### 미배정 또는 의도적으로 별도 처리

- `T`: 기존 엔버링크를 W로 옮겨 현재 비어 있음.
- `G`: 기존 프로미넌스를 R로 옮겨 현재 비어 있음.
- `7`, `8`, `Ctrl`, `Backquote` 등: 아직 사용자 확정 배치 없음.
- **사냥기(소드 스트라이크·페트리파이드 등):** 사용자가 다른 키 프리셋에서 기존 키를 교체해 사용하기로 결정. 이 보스용 표에 억지로 넣지 않는다.
- **스파이더 인 미러·크레스트 오브 더 솔라:** 사용자의 요청에 따라 보스용 키세팅 배정 대상에서 제외(별도 사냥 프리셋).
- **리셔플스위치: 방어모드, 블루 스트릭, 체인풀링, 귀환·장시간 버프 등:** 현 설계에 미배정. 미배정 ≠ 게임 내 사용 불가능/불필요로 단정한 것은 아님.

## 2. 평딜 입력군

평딜 중 자주 보는 스킬은 왼손 하단에 둔다. 극딜·준극에만 쓰는 스킬은 상단 QWERTY 라인에 모으고, 즉각적인 무적·기믹 조작은 검지의 반응성을 우선하는 것이 사용자의 키세팅 원칙이다.

```text
A = 기가 / 드라코 슬래셔
S = 윌 오브 소드 : 차지       (20초)
X = 인퍼널 브레스             (20초)
Z = 윌 오브 소드 : 스트라이크 (30초)
```

`A`로 평딜하며 준비된 `S/X/Z`를 사용한다. **키다운 공격은 `Page Down`**: 움직이지 못하는 동안 오른손으로 편하게 유지해 실수로 놓지 않으려는 사용자 선택이다. 익팅 중 왼손으로 `S` 및 `Z`를 사용할 수 있다.

## 3. 60초 준극 — W 단일 스킬

`W`에 **엔버링크 자체**를 배정한다. 준극을 위해 억지로 다른 버프를 묶지 않는다. 아래는 준비된 스킬을 활용하는 참고 입력 예시이며 고정 콤보가 아니다.

```text
W (엔버링크)
→ 준비된 Z / X / S / A
→ R (프로미넌스)는 변신/모프 게이지 상황에 따라 별도 판단
```

- `R` 프로미넌스는 60초 스킬이지만 **`W → R`을 필수 고정 콤보로 두지 않는다**.
- 풀극의 `2`에도 엔버링크가 **포함**되므로 중복 사용에 주의한다. 마제스티의 쿨타임 감소를 활용한 재사용은 추후 빌드 문제다.
- **W는 시퀀스가 아닌 단독 스킬**이다. 기존의 `T` 엔버링크 배치는 폐기한다.

## 4. 120초 극딜 — 2 시퀀스 및 실전 입력(참고안)

### 4-1. `2` 극딜 시퀀스 — 사용자 확정 순서 (서버렉 활용형)

**2026-10-24 확정:** 사용자 요청에 따라 **로버스트 아머와 바디 오브 스틸을 포함한 9종을 유지**하며, 서버 지연에 따른 버프 지속시간 연장 가능성을 고려한 아래 순서를 **목표 배치**로 선택했다.

이 순서는 2026-09-19 염화푸딩이 **향유 기준**으로 소개한 리레 5레벨 배열을 출발점으로 삼았다. **사용할 반지는 리레 4레벨을 기준으로 고려**하되, 동일 순서가 리레 4에서도 최고 DPS인지 검증한 자료는 확보하지 못했다. 여기서 '확정'은 사용자의 **설계 선택**이지 실측 최적화 판정이 아니다.

| 순서 | 시퀀스 등록 스킬 | 선택 이유·주의 |
|---:|---|---|
| 1 | 파이널 트랜스 | 즉시 변신 / 공격 준비 |
| 2 | 로버스트 아머 | 방어 버프. 공격 중 안정성 확보를 위해 유지 결정 |
| 3 | 바디 오브 스틸 | 경직·넉백 대응. 시퀀스에 포함하기로 결정 |
| 4 | 엔버링크(소울 컨트랙트) | 짧은 극딜 버프. `W`에도 별도 등록 |
| 5 | 가디언 오브 노바 | 소환 공격을 먼저 사용 |
| 6 | 리스트레인트 링 **4레벨 기준** | 공격 버프. 기존 리레 5용 배치 위치를 차용한 **미검증 순서** |
| 7 | 마제스티 오브 카이저 | 쿨타임 감소 효과. 리레 뒤에 배치 |
| 8 | 그란디스 여신의 축복 | 재사용 대기시간 미적용을 활용한 윌오소 연사 준비 |
| 9 | 드래곤 블레이즈 | 서버 지연 연장 활용을 기대하는 후행 극딜 스킬 |

```text
2 = 파이널 트랜스 → 로버스트 아머 → 바디 오브 스틸
  → 엔버링크 → 가디언 오브 노바 → 리레
  → 마제스티 → 그여축 → 드래곤 블레이즈
```

**서버 지연 활용 의도:** 특히 `리레 → 마제스티 → 그여축 → 드래곤 블레이즈` 순서를 유지한다. 리레·엔버링크처럼 특정 지속시간 연장 효과를 받지 않는 버프와, 드래곤 블레이즈처럼 서버 지연 영향이 보고된 스킬의 상대적 순서가 중요하다는 2026년 카이저 커뮤니티 실험·숙련자 공략을 참고했다. 다만 원래 실험에는 2026년 9월 개편 **이전** 자료도 포함되며, 10월 패치 이후 동일 현상과 정확한 증가량은 **미검증**이다. 보고된 '드래곤 블레이즈 공격 횟수 변화'를 전체 최종 데미지 증가율과 동일시하지 않는다.

**사용자 선택 이유:** 로버스트 아머·바디 오브 스틸은 직접적인 피해량 증가 버프는 아니지만, 극딜 중 생존과 끊김 방지 및 입력 편의성 때문에 **둘 다 시퀀스에 넣기로 결정**했다. 단축을 위해 임의로 삭제하지 않는다.

**파운틴·헤카테 주의:** 일부 과거 카이저 실험에서 홀리 파운틴과 솔 헤카테의 동시 활성화가 서버 지연에 따른 버프 연장 현상과 충돌할 수 있다는 **관찰 보고**가 있었다. 현재 본섭에서도 재현되는지 확인되지 않았으므로 확정 버그나 무조건적인 사용 금지로 단정하지 않는다. 현재 단축키는 `1` 파운틴, `9` 헤카테다.

### 4-2. 실전 극딜 예시 — 키 변환

아래는 2026-09-19 개편 후 커뮤니티 공략을 현재 키 후보에 대응한 **연습용 흐름**이다. 사용자가 직접 카이저를 육성하며 검증한 실전 입력 기록은 아니다.

**고점형 후오리진 (기본 검토안)**

```text
2 (풀극 버프) → E (판테온 VI, 개방 후)
→ Page Down 키다운 + S 연속 사용 / Z
→ X (인퍼널 브레스) → A (드라코)
→ 3 (오리진) → Q (일반 바인드) → 준비된 후속 공격
```

**선오리진 (파티·보스 조건별 대안)**

```text
2 → E → 3 (오리진)
→ Page Down 키다운 + S 연속 사용 / Z
→ Q → 준비된 X / S / A
```

- **오리진 위치를 옮겨도 키는 항상 3으로 유지**한다.
- 공략마다 바인드와 공격기 배치가 다르고 수로처럼 특수 시간표가 존재한다. 두 예시는 모든 상황에서 고정된 최적해가 아니다.
- `E`는 사용자가 기존 판테온과 판테온 VI의 동일 키 운용을 희망한 것. VI 코어 개방 및 자동 슬롯 교체 여부를 별개로 취급한다.
- `Y` 리레 단독 슬롯은 극딜 시퀀스에 중복 포함되더라도 쿨타임 상태 확인을 위한 것이다.

### 4-3. 검증 상태

- **사용자 확정:** `2` 극딜 / `W` 엔버링크 / `3` 오리진 / `E` 판테온→VI / `R` 프로미넌스 / `Page Down` 익팅 / `Y` 리레.
- **사용자가 확정한 설계:** 위 9종 및 서버렉 활용을 목표로 한 발동 순서. 로버스트 아머·바디 오브 스틸을 포함한다.
- **공략 근거의 한계:** 리레 5 기준 배열을 리레 4에 차용한 것으로, **리레 4 최고 DPS·2026년 10월 본섭 서버렉 재현성은 미검증**이다.
- **연구 중:** 선오리진·후오리진의 상대적 DPS, 바인드 순서, 리레 4와 버프 지속시간 및 서버 지연, 스킬 시퀀스 실제 등록·발동 동작.

## 5. 이동·생존 역할 대응

은월에서 익숙한 손의 의미를 최대한 유지한다.

```text
D      = 무적
F      = 어센트 무적
Shift  = 핵심 회피 / 텔레포트
Alt    = 돌진
End    = 버티컬 커넥트
Page Down = 익팅 키다운(오른손)
V      = 블링크
```

특히 `Alt = 피어스 러쉬`는 은월에서 Alt에 두던 공용 돌진과 역할을 맞춘다.
