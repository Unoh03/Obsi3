# 카이저 키세팅

> 최초 작성: 2026-09-25 / 목표 시퀀스 반영: 2026-10-14
>
> 목적: 은월에서 익숙한 키 역할을 최대한 유지하면서, 2026-09-17 본섭 1.2.419 이후 카이저 운용에 맞춘 보스용 키세팅을 고정한다.
>
> **설정 정책:** 장기 목표는 향유 기준으로 소개된 리레 5 고점형 W 시퀀스 하나로 고정한다. 아래는 **사용자가 선택한 목표 설정**이며, 향유 본인 화면을 직접 검증한 설정 또는 모든 스펙에서의 DPS 최적해라는 뜻은 아니다.
>
> **주의:** 실제 보스에서 손에 안 맞는 부분은 변경 가능하다. 오리진/일반 바인드의 세부 순서는 보스 및 파티 빌드에 따라 달라질 수 있으므로 키 위치와 극딜 순서를 분리한다.

## 1. 현재 키세팅

| 키 | 스킬 | 역할 / 메모 |
|---|---|---|
| `A` | 기가 슬래셔 / 드라코 슬래셔 | 상시 평딜. 드라코 사용 가능 시 강화 평딜 |
| `S` | 윌 오브 소드 : 차지 | 20초 주기. 익팅 중 연속 사용 핵심 |
| `X` | 인퍼널 브레스 | 20초 누킹기 |
| `Z` | 윌 오브 소드 : 스트라이크 | **30초** 누킹기 |
| `D` | 드래고닉 이지스 | 능동 무적 / 비상 생존 |
| `F` | 파이로 인스팅트 | 어센트. 강한 독립 공격 + 시전 중 무적 |
| `G` | 프로미넌스 | **60초**. 공격 + 비변신 시 모프 게이지 수급 |
| `Q` | 에르다 노바 | 일반 바인드 |
| `W` | 풀극딜 시퀀스 | 향유 기준 리레 5 고점형 9스킬 묶음. 상세 순서는 §4 |
| `E` | 판테온 VI | HEXA 개방 후 120초 공격기. **기존 5차 판테온(1200초)과 구분** |
| `R` | 드라코닉 익스팅션 | 키다운 극딜 본체 |
| `T` | 엔젤릭버스터 링크 | 준극 수동 시작용. W에도 포함되므로 풀극 직후 중복 입력 금지 |
| `Y` | 마이트 오브 노바 | 오리진 |
| `Shift` | 파이널 피규레이션 / 변신 중 텔레포트 | 주력 회피·이동 / 변신 |
| `Alt` | 피어스 러쉬 | 카이저의 표준 돌진 역할. 은월의 공용 돌진 자리 유지 |
| `V` | 블링크 | 공중 체공 |
| `3` | 의지 | 상태이상 해제 |
| `4` | 파운틴 | 설치기 |
| `5 / 6` | 야누스 | 사냥 |
| `Ctrl` | 미정 | 현재 비워둠 |
| `9 / 0 / - / =` | 온오프 계열 | 윌 오브 소드 / 에르다 페미에이션 / 솔 헤카테 / 리셔플 스위치 배치 후보. 세부 순서 미정 |

## 2. 평딜 입력군

평딜 중 자주 보는 스킬은 왼손 하단에 모은다.

```text
A = 기가 / 드라코
S = 윌 오브 소드 : 차지   (20초)
X = 인퍼널 브레스          (20초)
Z = 윌 오브 소드 : 스트라이크 (30초)
```

기본 개념:

```text
A A A...
→ S / X / Z가 돌아오면 사용
→ 다시 A
```

카이저는 극딜에서도 이 평딜 입력군을 그대로 많이 사용한다. 별도의 극딜 전용 공격 버튼을 다수 추가하기보다, 익팅과 극딜 버프 안에서 평소 쓰던 공격기를 몰아치는 구조로 본다.

## 3. 60초 준극

준극의 시작 버튼은 `T`(엔버링크). 준비된 `S/X/Z/A` 공격을 몰아친다.

```text
T
→ Z / X / S / A (사용 가능 스킬 위주)
→ G는 비변신 모프 게이지 수급 필요 여부에 따라 별도 판단
```

- `G`(프로미넌스)는 60초 공격기이자 비변신 시 게이지 수급 수단이다. **`T → G`를 필수 고정 콤보로 두지 않는다.**
- 변신이 끊기거나 게이지가 부족하다면 게이지 확보를 위해 `G`를 고려한다.
- 스킬 사용 가능 여부와 보스 패턴을 우선한다. 프로미넌스의 최적 타이밍은 최신 실험에서 확정되지 않았다.
- 풀극에서 W가 엔버링크를 사용하므로 `W` 직후 `T`를 또 누르지 않는다.


## 4. 120초 풀극 — 선택한 최종 목표

### 4-1. `W` 내부 시퀀스 (고정 목표 순서)

2026-09-19 염화푸딩이 **향유 기준**으로 공유한 리레 5 고점형 배열을 목표로 한다. 본인 원본 설정을 직접 확인한 결과는 아니며, 초기 챌린저스 월드에서는 미보유 스킬·시드링을 그대로 구현할 수 없다.

| 순서 | 스킬 | 메모 |
|---:|---|---|
| 1 | 파이널 트랜스 | 즉시 변신 |
| 2 | 로버스트 아머 | 방어 버프 |
| 3 | 바디 오브 스틸 | 방어·경직 대응 |
| 4 | 엔젤릭버스터 링크 | 극딜 버프; T는 준극 수동용 |
| 5 | 가디언 오브 노바 | 소환 공격 |
| 6 | 리스트레인트 링 5레벨 | 최종 목표 시드링 |
| 7 | 마제스티 오브 카이저 | 쿨타임 감소 등 |
| 8 | 그란디스 여신의 축복 | 피해 증가·재사용 대기시간 초기화 |
| 9 | 드래곤 블레이즈 | 극딜 공격 버프 |

핵심 배치 원칙: **리레 5와 드래곤 블레이즈를 바로 붙이지 않고, 그 사이에 마제스티 및 그여축을 배치**한다. 관련 서버 지연 관찰은 개편 전 실험에도 근거하므로 2026-09-17 이후 본섭에서 동일하게 재현되는지는 미확정이다.

로버스트 아머와 바디 오브 스틸은 선택한 원본 배열을 보존한 것이다. 시퀀스 시간 단축을 위해 빼자는 다른 유저 의견도 있으므로 두 스킬이 보편적 필수라는 뜻은 아니다.

### 4-2. `W` 이후 수동 입력

```text
W (위 9스킬 순차 실행)
→ E (판테온 VI, HEXA 개방 후)
→ R 키다운 + Z / S 연속 발사
→ R 해제
→ X / A
→ Y (오리진)
→ Q (일반 바인드)
→ 돌아온 공격기
```

압축 암기: `WE → R + ZSSSSSS → XA → YQ...`

- `R` 유지 중 `S`를 연속 사용하는 것이 핵심. `Z`도 사용 가능 타이밍에 입력한다.
- `Y → Q`는 현재 선택한 **고점형 기본 순서**이지 모든 보스의 절대 규칙은 아니다. 선오리진·후오리진 또는 파티 바인드 요구가 있으면 예외가 생긴다.
- `E`는 **판테온 VI를 배웠을 때만** 이 순서에 들어간다. 일반 5차 판테온과 동일시하지 않는다.
- `W`에 엔버링크가 있으므로 풀극과 동시에 `T`를 중복 사용하지 않는다.
- 챌섭 육성 중 리레 5레벨을 아직 보유하지 않았을 때는 해당 슬롯만 임시 제외하고 나머지 상대적 순서를 유지한다. 실제 스킬 습득·지속시간·사용 가능 조건에 맞춰 시퀀스 정상 실행을 확인해야 한다.

### 4-3. 검증 상태

- 확정: **사용자가 목표로 선택한 키 배치와 W의 9개 입력 순서**.
- 참고 근거: 2026-09-19 개편 후 커뮤니티 숙련 공략에서 인용한 향유 기준 배열.
- 미확정: 향유 본인의 현재 실사용 세팅, 리레 5 서버 지연 효율의 최신 재현성, 모든 보스에서의 최적화, 방어 버프 2개의 필요성.


## 5. 이동·생존 역할 대응

은월에서 익숙한 손의 의미를 최대한 유지한다.

```text
D      = 무적
F      = 어센트 무적
Shift  = 핵심 회피 / 텔레포트
Alt    = 돌진
V      = 블링크
```

특히 `Alt = 피어스 러쉬`는 은월에서 Alt에 두던 공용 돌진과 역할을 맞춘다.

## 6. 검증·정정 기록

### 현재 기준

- 윌 오브 소드 : 차지 = **20초**
- 인퍼널 브레스 = **20초**
- 윌 오브 소드 : 스트라이크 = **30초**
- 프로미넌스 = **60초** (모프 게이지 수급용 보존 여부 조건부)

- 프로미넌스의 과거 무적 역할은 현재 드래고닉 이지스로 분리됨
- 피어스 러쉬는 현재 공격기보다 이동용 돌진기로 취급
