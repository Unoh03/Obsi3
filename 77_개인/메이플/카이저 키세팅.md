# 카이저 키세팅

> 최초 작성: 2026-09-25 / 키 재설계: 2026-10-23
>
> 목적: 은월에서 익숙한 키 역할을 최대한 유지하면서, 2026-09-17 본섭 1.2.419 이후 카이저 운용에 맞춘 보스용 키세팅을 고정한다.
>
> **설정 정책:** 사용자가 2026-10-23 대화에서 확정한 **장래의 키 배치 설계안**을 우선 기록한다. 현재 카이저를 육성해 실제 게임에 적용한 상태는 아니다. 버프 시퀀스 `2`의 내부 순서는 **리레 4 기준 미확정**이며, 과거 리레 5 목표 배열은 참고용으로 남긴다.
>
> **주의:** 실제 보스에서 손에 안 맞는 부분은 변경 가능하다. 오리진/일반 바인드의 세부 순서는 보스 및 파티 빌드에 따라 달라질 수 있으므로 키 위치와 극딜 순서를 분리한다.

### 미배정 또는 의도적으로 별도 처리

- `T`: 기존 엔버링크를 W로 옮겨 현재 비어 있음.
- `G`: 기존 프로미넌스를 R로 옮겨 현재 비어 있음.
- `7`, `8`, `Ctrl`, `Backquote` 등: 아직 사용자 확정 배치 없음.
- **사냥기(소드 스트라이크·페트리파이드 등):** 사용자가 다른 키 프리셋에서 기존 키를 교체해 사용하기로 결정. 이 보스용 표에 억지로 넣지 않는다.
- **스파이더 인 미러·크레스트 오브 더 솔라:** 사용자의 요청에 따라 보스용 키세팅 배정 대상에서 제외(별도 사냥 프리셋).
- **리셔플스위치: 방어모드, 블루 스트릭, 체인풀링, 귀환·장시간 버프 등:** 현 설계에 미배정. 미배정 ≠ 게임 내 사용 불가능/불필요로 단정한 것은 아님.

## 2. 평딜 입력군

평딜 중 자주 보는 스킬은 왼손 하단에 둔다. 극딜·준극에만 쓰는 스킬은 상단 QWERTY 라인에 모으고, 즉각적인 무적·기믹 조작은 검지의 반응성을 우선하는 것이 사용자의 키세팅 원칙이다.

```text
A = 기가 / 드라코 슬래셔
S = 윌 오브 소드 : 차지       (20초)
X = 인퍼널 브레스             (20초)
Z = 윌 오브 소드 : 스트라이크 (30초)
```

`A`로 평딜하며 준비된 `S/X/Z`를 사용한다. **키다운 공격은 `Page Down`**: 움직이지 못하는 동안 오른손으로 편하게 유지해 실수로 놓지 않으려는 사용자 선택이다. 익팅 중 왼손으로 `S` 및 `Z`를 사용할 수 있다.

## 3. 60초 준극 — W 단일 스킬

`W`에 **엔버링크 자체**를 배정한다. 준극을 위해 억지로 다른 버프를 묶지 않는다. 아래는 준비된 스킬을 활용하는 참고 입력 예시이며 고정 콤보가 아니다.

```text
W (엔버링크)
→ 준비된 Z / X / S / A
→ R (프로미넌스)는 변신/모프 게이지 상황에 따라 별도 판단
```

- `R` 프로미넌스는 60초 스킬이지만 **`W → R`을 필수 고정 콤보로 두지 않는다**.
- 풀극의 `2`에도 엔버링크가 포함될 수 있으므로 중복 사용에 주의한다. 마제스티의 쿨타임 감소를 활용한 재사용은 추후 빌드 문제다.
- **W는 시퀀스가 아닌 단독 스킬**이다. 기존의 `T` 엔버링크 배치는 폐기한다.

## 4. 120초 극딜 — 2 시퀀스 및 실전 입력(참고안)

### 4-1. `2`에 이전할 버프 시퀀스 — 과거 리레 5 목표 배열

기존 파일의 `W` 9스킬 배열은 2026-09-19 염화푸딩이 향유 기준으로 공유한 **리레 5 고점형 참고안**이었다. 사용자는 `2`를 풀극 시퀀스 키로 **확정**했지만, 다음 **내부 9스킬의 상대적 순서는 리레 4 기준으로 확정하지 않았다**. 과거 배열을 검토 근거로 보존한다.

| 순서(과거 참고안) | 스킬 | 메모 |
|---:|---|---|
| 1 | 파이널 트랜스 | 즉시 변신 |
| 2 | 로버스트 아머 | 피해 감소 버프 |
| 3 | 바디 오브 스틸 | 경직 대응 |
| 4 | 엔버링크 | 현재는 W로도 단독 배치 |
| 5 | 가디언 오브 노바 | 소환 공격 |
| 6 | 리스트레인트 링 **5레벨** | **현재 연구 기준 리레 4와 다름** |
| 7 | 마제스티 오브 카이저 | 쿨타임 감소 |
| 8 | 그란디스 여신의 축복 | 재사용 대기시간 미적용 등 |
| 9 | 드래곤 블레이즈 | 극딜 공격 버프 |

과거 설계 의도는 리레와 드래곤 블레이즈 사이에 마제스티·그여축을 배치해 서버 지연상 효과를 노리는 것이었다. 해당 실험은 2026년 개편 전 자료도 참고했으므로 **2026-10-23 현재 리레 4에서 그대로 최적이라고 확정할 수 없다**. 로버스트 아머와 바디 오브 스틸을 시퀀스에 둘 필요도 추가 검토 대상으로 둔다.

### 4-2. 실전 극딜 예시 — 키 변환

아래는 2026-09-19 개편 후 커뮤니티 공략을 현재 키 후보에 대응한 **연습용 흐름**이다. 사용자가 직접 카이저를 육성하며 검증한 실전 입력 기록은 아니다.

**고점형 후오리진 (기본 검토안)**

```text
2 (풀극 버프) → E (판테온 VI, 개방 후)
→ Page Down 키다운 + S 연속 사용 / Z
→ X (인퍼널 브레스) → A (드라코)
→ 3 (오리진) → Q (일반 바인드) → 준비된 후속 공격
```

**선오리진 (파티·보스 조건별 대안)**

```text
2 → E → 3 (오리진)
→ Page Down 키다운 + S 연속 사용 / Z
→ Q → 준비된 X / S / A
```

- **오리진 위치를 옮겨도 키는 항상 3으로 유지**한다.
- 공략마다 바인드와 공격기 배치가 다르고 수로처럼 특수 시간표가 존재한다. 두 예시는 모든 상황에서 고정된 최적해가 아니다.
- `E`는 사용자가 기존 판테온과 판테온 VI의 동일 키 운용을 희망한 것. VI 코어 개방 및 자동 슬롯 교체 여부를 별개로 취급한다.
- `Y` 리레 단독 슬롯은 극딜 시퀀스에 중복 포함되더라도 쿨타임 상태 확인을 위한 것이다.

### 4-3. 검증 상태

- **사용자 확정:** `2` 극딜 / `W` 엔버링크 / `3` 오리진 / `E` 판테온→VI / `R` 프로미넌스 / `Page Down` 익팅 / `Y` 리레.
- **과거 목표 참고자료:** 리레 5 기준 버프 9종 배열. **현재 리레 4 기준 시퀀스 내부 순서 미확정.**
- **연구 중:** 선오리진·후오리진의 상대적 DPS, 바인드 순서, 리레 4와 버프 지속시간 및 서버 지연, 스킬 시퀀스 실제 등록·발동 동작.

## 5. 이동·생존 역할 대응

은월에서 익숙한 손의 의미를 최대한 유지한다.

```text
D      = 무적
F      = 어센트 무적
Shift  = 핵심 회피 / 텔레포트
Alt    = 돌진
End    = 버티컬 커넥트
Page Down = 익팅 키다운(오른손)
V      = 블링크
```

특히 `Alt = 피어스 러쉬`는 은월에서 Alt에 두던 공용 돌진과 역할을 맞춘다.

## 6. 검증·정정 기록

### 현재 기준

- 윌 오브 소드 : 차지 = **20초**
- 인퍼널 브레스 = **20초**
- 윌 오브 소드 : 스트라이크 = **30초**
- 프로미넌스 = **60초** (모프 게이지 수급용 보존 여부 조건부)
- 기존 5차 판테온과 HEXA 판테온 VI의 재사용 대기시간 및 역할을 구분할 것
- 프로미넌스의 과거 무적 역할은 현재 드래고닉 이지스로 분리됨
- 피어스 러쉬는 현재 공격기보다 이동용 돌진기로 취급

### 폐기된 오정보

- ~~E = 5차 판테온이 120초 극딜 공격기~~ → **폐기. E의 장기 목표는 판테온 VI**
- ~~T → G가 필수 고정 준극 콤보~~ → **폐기. 준극은 W=엔버링크, R=프로미넌스는 별도 판단**

- ~~윌 오브 소드 : 스트라이크 = 60초~~ → **폐기. 현재 30초**
- ~~프로미넌스 = 현재 카이저 무적기~~ → **폐기. 현재 능동 무적은 드래고닉 이지스**
- ~~Ctrl = 피어스 러쉬 + Alt = 별도 공용 돌진~~ → **폐기. 피어스 러쉬 자체를 Alt의 돌진 역할로 사용**

### 2026-10-23 키세팅 재설계

- `W`의 옛 극딜 시퀀스를 `2`로 이동, `W`는 엔버링크 단독으로 변경. 기존 `T` 엔버링크 제거.
- 오리진 `Y → 3`; 리레 쿨 확인용 `Y` 배정; 프로미넌스 `G → R`; 익팅 `R → Page Down`.
- 은월과 맞춰 `1` 파운틴, `4` 노바 용사의 의지, `5` 에르다의 의지, `6` 솔 야누스, `C` 상호작용.
- `End` 버티컬 커넥트, `-` 윌 오브 소드 온·오프, `=` 공격모드.
- 최종 충돌 해결: **`9` 솔 헤카테 / `0` 에르다 페미에이션**.
- 사냥기는 별도 프리셋으로 분리하고, 스파이더 인 미러·크레스트 오브 더 솔라는 사용자가 메인 보스 키세팅에 넣지 않기로 결정했다.
- 기존 리레 5 목표 시퀀스를 현 리레 4 최적안으로 단정하지 않고 참고 배치로 격하했다.
