# 카이저 키세팅

> 최초 작성: 2026-09-25 / 키 재설계: 2026-10-23 / 극딜 시퀀스 순서 확정: 2026-10-24 / 은월 연동 키 재배치: 2026-11-04 / 공격·방어 분리 설계: 2026-11-04
>
> 목적: 은월에서 익숙한 키 역할을 최대한 유지하면서, 2026-09-17 본섭 1.2.419 이후 카이저 운용에 맞춘 보스용 키세팅을 고정한다.
>
> **설정 정책:** 사용자가 2026-10-23~24 대화에서 확정한 **장래의 키 배치 및 극딜 시퀀스 설계안**을 우선 기록한다. 현재 카이저를 육성해 실제 게임에 적용한 상태는 아니다. 2026-11-04 은월 변경사항을 반영했으며, **공격 시퀀스 `1`에서 방어 버프 2개를 빼 별도 방어 시퀀스로 분리**한다는 새 사용자 요청을 반영한다. `1`은 공격 관련 7종이며, `E` 방어 시퀀스와 세 번째 스킬 `리게인 스트렝스`는 **검증 전 제안**이다. 리레 4레벨에서 서버렉/최적 딜은 실측 검증되지 않았다.
>
> **주의:** 실제 보스에서 손에 안 맞는 부분은 변경 가능하다. 오리진/일반 바인드의 세부 순서는 보스 및 파티 빌드에 따라 달라질 수 있으므로 키 위치와 극딜 순서를 분리한다.

### 미배정 또는 의도적으로 별도 처리

- `E`: 프로미넌스를 `T`로 옮긴 후 **방어 시퀀스 배정 후보**. 사용자가 위치까지 확정한 것은 아니므로 제안 상태로 기록.
- `T`: 현재 프로미넌스 배정. 이전에 미배정이었으나 2026-11-04 재배치 완료.
- `G`: 과거 프로미넌스 배치 후 비워 둔 키. 프로미넌스 최신 위치는 `T`.
- `7`, `8`, `Ctrl`, `Backquote` 등: 아직 사용자 확정 배치 없음.
- **사냥기(소드 스트라이크·페트리파이드 등):** 사용자가 다른 키 프리셋에서 기존 키를 교체해 사용하기로 결정. 이 보스용 표에 억지로 넣지 않는다.
- **스파이더 인 미러·크레스트 오브 더 솔라:** 사용자의 요청에 따라 보스용 키세팅 배정 대상에서 제외(별도 사냥 프리셋).
- **리셔플스위치: 방어모드, 블루 스트릭, 체인풀링, 귀환·장시간 버프 등:** 현 설계에 미배정. 미배정 ≠ 게임 내 사용 불가능/불필요로 단정한 것은 아님.

## 2. 평딜 입력군

평딜 중 자주 보는 스킬은 왼손 하단에 둔다. 극딜·준극에만 쓰는 스킬은 상단 QWERTY 라인에 모으고, 즉각적인 무적·기믹 조작은 검지의 반응성을 우선하는 것이 사용자의 키세팅 원칙이다.

```text
A = 기가 / 드라코 슬래셔
S = 윌 오브 소드 : 차지       (20초)
X = 인퍼널 브레스             (20초)
Z = 윌 오브 소드 : 스트라이크 (30초)
```

`A`로 평딜하며 준비된 `S/X/Z`를 사용한다. **키다운 공격은 `Page Down`**: 움직이지 못하는 동안 오른손으로 편하게 유지해 실수로 놓지 않으려는 사용자 선택이다. 익팅 중 왼손으로 `S` 및 `Z`를 사용할 수 있다.

## 3. 60초 준극 — Q 단일 스킬

`Q`에 **엔버링크 자체**를 배정한다. 준극을 위해 억지로 다른 버프를 묶지 않는다. 아래는 준비된 스킬을 활용하는 참고 입력 예시이며 고정 콤보가 아니다.

```text
Q (엔버링크)
→ 준비된 Z / X / S / A
→ T (프로미넌스)는 변신/모프 게이지 상황에 따라 별도 판단
```

- `T` 프로미넌스는 60초 스킬이지만 **`Q → T`를 필수 고정 콤보로 두지 않는다**.
- 풀극의 `1`에도 엔버링크가 **포함**되므로 중복 사용에 주의한다. 마제스티의 쿨타임 감소를 활용한 재사용은 추후 빌드 문제다.
- **Q는 시퀀스가 아닌 단독 스킬**이다. 이전 `T`, `W` 배치는 과거 기록이다.

## 4. 공격·방어 스킬 시퀀스 및 실전 입력(참고안)

### 4-1. `1` 공격 시퀀스 — 방어 버프 분리 (2026-11-04)

**사용자 새 결정:** 극딜 시퀀스에는 공격·극딜에 필요한 스킬만 넣는다. 이전 9종에서 **로버스트 아머, 바디 오브 스틸을 제외**하고 다음 **7종**을 공격용으로 분리한다.

| 순서 | 공격 시퀀스 등록 스킬 | 메모 |
|---:|---|---|
| 1 | 파이널 트랜스 | 변신으로 공격 준비 |
| 2 | 엔버링크(소울 컨트랙트) | `Q`에도 단독 배정 |
| 3 | 가디언 오브 노바 | 극딜 소환 공격 |
| 4 | 리스트레인트 링 **4레벨 기준** | 시드링. `Y`에서 쿨타임 별도 확인 |
| 5 | 마제스티 오브 카이저 | 재사용 대기시간 감소 및 공격 운영 |
| 6 | 그란디스 여신의 축복 | 극딜 공격 버프 |
| 7 | 드래곤 블레이즈 | 극딜 공격 버프 |

```text
1 = 파이널 트랜스 → 엔버링크 → 가디언 오브 노바
  → 리레 → 마제스티 → 그여축 → 드래곤 블레이즈
```

**서버렉 관련 제한:** 이전 9종의 상대적 순서를 유지하며 방어 스킬 두 개를 단순 제거한 **설계안**이다. 과거 커뮤니티 리레 5 실험에서 제안한 배치와 발동 시간이 달라질 수 있으며, 리레 4에서 드래곤 블레이즈 서버렉 연장·총딜이 최적인지 검증되지 않았다. 본 변경으로 기존 9종이 7종으로 바뀌므로, 이전 9종을 '최신 확정'으로 취급하지 않는다.

### 4-1a. `E` 방어 시퀀스 — 등록 3종 **제안**

넥슨 공식 스킬 가이드에 따르면 **스킬 시퀀스는 최소 3종 이상** 등록해야 한다. 로버스트 아머와 바디 오브 스틸만으로는 시퀀스가 성립하지 않는다.

| 순서 | 방어 시퀀스 등록 후보 | 역할·조건 |
|---:|---|---|
| 1 | 로버스트 아머 | 시간 제한 피해 감소 버프, 위험 패턴 전 사용 |
| 2 | 바디 오브 스틸 | 슈퍼 스탠스·경직/넉백 대응 |
| 3 | 리게인 스트렝스 | 상태이상·속성 내성 버프, **최소 3종 조건을 채우는 후보** |

```text
E (배정 후보) = 로버스트 아머 → 바디 오브 스틸 → 리게인 스트렝스
```

- **확정된 것은 공격/방어를 분리한다는 사용자의 의도**다. `E` 키 배치와 세 번째 스킬은 제안 상태이며, 인게임 적용·등록 가능 여부를 확인할 필요가 있다.
- 리게인 스트렝스는 카이저 커뮤니티 스킬 데이터에서 시퀀스 및 **펫 자동 버프 등록 가능**으로 설명된다. **이미 펫 버프로 상시 유지한다면 방어 시퀀스의 세 번째 스킬로는 사실상 중복/채움용**이다. 또한 상태이상 몬스터 공격 시 최종 데미지 증가 효과도 가진 혼합형 버프이지, 순수 방어 전용 스킬은 아니다.
- **즉시 대응용 무적·의지·판테온은 이 시퀀스에 넣지 않는다.** 이지스 `D`, 의지 `4/5`, 판테온 `W`, 파이로 인스팅트 `F`는 각각 개별 제어를 유지한다. 스킬 시퀀스는 등록 순서대로 작은 딜레이를 두고 사용되므로 즉시 무적기 대체 수단이 아니다.
- 모험가 전사 공용 **블리츠 실드 VI는 카이저 공용기가 아니다.** 카이저 방어 시퀀스의 세 번째 스킬로 사용하지 않는다. 쓸만한 하이퍼 바디는 최대 HP만 올리는 특성상 HP 비례 패턴 대비 긴급 방어로 추천하지 않는다.
- 방어 시퀀스는 **패턴을 예상해 미리 켜는 버프 묶음**이다. 로버스트 아머·바디 오브 스틸의 지속시간·쿨타임을 고려해 공격 시퀀스와 따로 판단한다. 두 버프 모두 쿨타임이면 세 번째 장시간 버프만 눌리는 상황도 있을 수 있다.

### 4-2. 실전 극딜 예시 — 키 변환

아래는 2026-09-19 개편 후 커뮤니티 공략을 현재 키 후보에 대응한 **연습용 흐름**이다. 사용자가 직접 카이저를 육성하며 검증한 실전 입력 기록은 아니다.

**고점형 후오리진 (기본 검토안)**

```text
1 (풀극 버프) → W (판테온 VI, 개방 후)
→ Page Down 키다운 + S 연속 사용 / Z
→ X (인퍼널 브레스) → A (드라코)
→ 2 (오리진) → R (일반 바인드) → 준비된 후속 공격
```

**선오리진 (파티·보스 조건별 대안)**

```text
1 → W → 2 (오리진)
→ Page Down 키다운 + S 연속 사용 / Z
→ R → 준비된 X / S / A
```

- **오리진 위치를 옮겨도 키는 항상 `2`로 유지**한다.
- 공략마다 바인드와 공격기 배치가 다르고 수로처럼 특수 시간표가 존재한다. 두 예시는 모든 상황에서 고정된 최적해가 아니다.
- `W`는 사용자가 기존 판테온과 판테온 VI의 동일 키 운용을 희망한 것. VI 코어 개방 및 자동 슬롯 교체 여부를 별개로 취급한다.
- `Y` 리레 단독 슬롯은 극딜 시퀀스에 중복 포함되더라도 쿨타임 상태 확인을 위한 것이다.

### 4-3. 검증 상태

- **2026-11-04 최신 사용자 확정:** `1` 공격 7종 / `2` 오리진 / `3` 파운틴 / `Q` 엔버링크 / `W` 판테온→VI / `R` 일반 바인드 / `T` 프로미넌스 / `Page Down` 익팅 / `Y` 리레.
- **방어 시퀀스는 제안:** `E`에 로버스트 아머·바디 오브 스틸·리게인 스트렝스 후보 3종. `E` 확정 및 3번째 스킬 채택은 미결정.
- **공략 근거의 한계:** 리레 5 기준 배열을 리레 4에 차용한 것으로, **리레 4 최고 DPS·2026년 10월 본섭 서버렉 재현성은 미검증**이다.
- **연구 중:** 선오리진·후오리진의 상대적 DPS, 바인드 순서, 리레 4와 버프 지속시간 및 서버 지연, 스킬 시퀀스 실제 등록·발동 동작.

## 5. 이동·생존 역할 대응

은월에서 익숙한 손의 의미를 최대한 유지한다.

```text
D      = 무적
F      = 어센트 무적
Shift  = 핵심 회피 / 텔레포트
Alt    = 돌진
End    = 버티컬 커넥트
Page Down = 익팅 키다운(오른손)
V      = 블링크
```

특히 `Alt = 피어스 러쉬`는 은월에서 Alt에 두던 공용 돌진과 역할을 맞춘다.

### 2026-10-23 키세팅 재설계

- `W`의 옛 극딜 시퀀스를 `2`로 이동, `W`는 엔버링크 단독으로 변경. 기존 `T` 엔버링크 제거.
- 오리진 `Y → 3`; 리레 쿨 확인용 `Y` 배정; 프로미넌스 `G → R`; 익팅 `R → Page Down`.
- 은월과 맞춰 `1` 파운틴, `4` 노바 용사의 의지, `5` 에르다의 의지, `6` 솔 야누스, `C` 상호작용.
- `End` 버티컬 커넥트, `-` 윌 오브 소드 온·오프, `=` 공격모드.
- 최종 충돌 해결: **`9` 솔 헤카테 / `0` 에르다 페미에이션**.
- 사냥기는 별도 프리셋으로 분리하고, 스파이더 인 미러·크레스트 오브 더 솔라는 사용자가 메인 보스 키세팅에 넣지 않기로 결정했다.
- 기존 리레 5 목표 시퀀스는 당시 리레 4 최적성 판단을 유보하여 참고 배치로 격하했다. **2026-10-24 사용자가 동일 9종 및 상대적 순서를 서버렉 활용형 목표로 다시 선택했으나, 실측 최적성은 여전히 미검증이다.**

### 2026-10-24 서버렉 활용형 시퀀스 확정

- `2` 버프 시퀀스를 **파이널 트랜스 → 로버스트 아머 → 바디 오브 스틸 → 엔버링크 → 가디언 오브 노바 → 리레 → 마제스티 → 그여축 → 드래곤 블레이즈** 순으로 확정(설계안).
- 버프 9종 모두 유지. **리레 4레벨 기준 최적 딜량·서버 지연 실측 결과는 아직 없음**을 명시.
- 홀리 파운틴·솔 헤카테 동시 활성화 관련 오래된 서버 지연 관찰을 검증 필요 사항으로 기록.

### 2026-11-04 은월 연동 키세팅 변경 (최신)

- 사용자가 은월에서 실제로 변경한 키세팅의 역할을 **카이저의 장래 키 배치에도 적용**하기로 함.
- 숫자열: `1` 극딜 시퀀스 / `2` 마이트 오브 노바(오리진) / `3` 쓸만한 홀리 파운틴.
- `QWER`: `Q` 엔버링크 / `W` 판테온→판테온 VI / `E` 프로미넌스 / `R` 에르다 노바(일반 바인드).
- **9종 극딜 버프 구성과 내부 순서는 그대로 유지**, 해당 시퀀스를 `2`에서 `1`로 옮겼음. 나머지 확정 키 배치는 유지.
- 이 절 이전의 `2` 극딜·`W` 엔버링크 등은 **당시 변경 이력**이며 현재 배치가 아님.

### 2026-11-04 프로미넌스 T 이동 (최신)

- 사용자 요청으로 **프로미넌스 `E → T`** 변경, `E`는 **미배정**으로 둔다.
- 그 외 현재 키 배치와 `1` 극딜 시퀀스 9종은 유지한다.
- 이전 기록의 `E=프로미넌스`는 역사적 배치이며 현재 배치는 `T=프로미넌스`이다.

### 2026-11-04 공격·방어 시퀀스 분리 (최신)

- 사용자 요청: **"방어 시퀀스를 만들고 싶다. 극딜 시퀀스엔 딱 딜만 넣고"**.
- `1` 극딜 시퀀스에서 방어용 **로버스트 아머·바디 오브 스틸 삭제**. 현재 목표 공격 시퀀스는 7종.
- 메이플 공식 스킬 시퀀스 **최소 3개 등록** 조건 때문에, 별도 방어 시퀀스에는 두 핵심 방어 버프와 세 번째 후보가 필요함.
- **`E` 방어 시퀀스 제안:** 로버스트 아머 → 바디 오브 스틸 → 리게인 스트렝스. 인게임 등록 검증과 최종 사용자 승인 전에는 **확정 배치로 표기하지 않는다**.
- `D` 이지스, `4/5` 의지, `F` 어센트 무적 등 즉시 대응 스킬은 별도 키 유지.
- 2026-10-24의 **9종 서버렉 활용형 시퀀스는 과거 결정 이력**으로만 보존. 7종의 서버렉 연장 및 리레 4 효율은 재검증 필요.
