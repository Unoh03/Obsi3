# 카이저 키세팅

은월에서 쓰던 키 역할을 살린 보스용 배치안이다. 카이저 인게임 적용·검증 기록은 없다.

## 1. 키 배치

| 키 | 스킬·기능 | 역할 |
|---|---|---|
| `1` | 극딜 시퀀스 | 120초·스킬 8종 |
| `2` | 마이트 오브 노바 | 오리진 |
| `3` | 쓸만한 홀리 파운틴 | 회복 설치 |
| `4` | 노바 용사의 의지 | 의지 |
| `5` | 에르다의 의지 | 의지 |
| `6` | 솔 야누스 | 사냥 |
| `9` | 에르다 페미에이션 | — |
| `0` | 솔 헤카테 | — |
| `-` | 윌 오브 소드 온·오프 | 차지 `S`와 별개 |
| `=` | 리셔플스위치: 공격모드 | 온·오프 |
| `Q` | 엔젤릭버스터 링크(소울 컨트랙트) | 60초 준극용 단독 스킬 |
| `W` | 판테온 → 판테온 VI | VI 개방 후 같은 키에서 운용 |
| `E` | 솔 헤카테 : 스틱스 | 수동 짧은 바인드·준극/패턴 대응 |
| `R` | 에르다 노바 | 일반 바인드 |
| `T` | 방어 시퀀스 | 키 배치 확정·구성은 제안 |
| `Y` | 리스트레인트 링 | 쿨타임 확인 |
| `A` | 기가 슬래셔 / 드라코 슬래셔 | 주력 평딜 |
| `S` | 윌 오브 소드 : 차지 | 20초 공격·익팅 중 연타 |
| `D` | 드래고닉 이지스 | 즉시 무적 |
| `F` | 파이로 인스팅트 | 어센트 무적 |
| `G` | 프로미넌스 | 60초 공격·모프 게이지 보충 |
| `Z` | 윌 오브 소드 : 스트라이크 | 30초 공격 |
| `X` | 인퍼널 브레스 | 20초 공격 |
| `C` | 채집 / NPC 대화 / 기믹 | 상호작용 |
| `V` | 블링크 | 공중 체공 |
| `Shift` | 파이널 피규레이션 / 변신 중 텔레포트 | 변신·회피 |
| `Alt` | 피어스 러쉬 | 돌진 |
| `End` | 버티컬 커넥트 | 상향 이동 |
| `Page Down` (`PgDn`) | 드라코닉 익스팅션 | 오른손 키다운 |

- 미배정 키는 `7`, `8`, `Ctrl`, `Backquote` 등이다. `Delete`는 익팅 후보에서 제외했다.
- 소드 스트라이크·페트리파이드 등 사냥기와 스파이더 인 미러·크레스트 오브 더 솔라는 사냥 프리셋을 쓴다.
- 방어모드·블루 스트릭·체인풀링·귀환·장시간 버프는 보스용 배치에서 미배정이다.

## 2. 평딜 입력

`A`로 평딜하면서 준비된 `S`·`X`·`Z`를 쓴다. 익팅 중에는 오른손으로 `Page Down`을 유지하며 왼손으로 `S`를 연타하거나 `Z`를 쓸 수 있다.

## 3. 60초 준극

`Q` 엔버링크 → 필요하면 `E` 스틱스 → 준비된 `Z`·`X`·`S`·`A`. `G` 프로미넌스는 변신과 모프 게이지를 보고 따로 쓴다.

엔버링크는 `1` 극딜 시퀀스에도 들어간다. 마제스티를 활용한 재사용 타이밍은 극딜 빌드 검증 항목이다.

## 4. 스킬 시퀀스와 극딜 입력

### 4-1. `1` 극딜 시퀀스

1. 엔버링크(소울 컨트랙트)
2. 그란디스 여신의 축복
3. 파이널 피규레이션
4. 파이널 트랜스
5. 가디언 오브 노바
6. 드래곤 블레이즈
7. 마제스티 오브 카이저
8. 리스트레인트 링(4레벨)

리레 4에서 드래곤 블레이즈의 서버렉 연장과 총딜은 실측 전이다.

> 본섭 1.2.419 이후 카이저 유저의 극딜 시퀀스를 연무장 리플레이·공략·보스 영상에서 최대한 많이 모아 추가로 비교한다. 리레 레벨과 오리진 순서, 사용 상황을 함께 기록한다.

### 4-1a. `T` 방어 시퀀스

로버스트 아머(피해 감소) → 바디 오브 스틸(넉백 대응) → 리게인 스트렝스(세 번째 후보).

- 시퀀스 등록에는 최소 3종이 필요하다. 리게인 스트렝스는 내성과 조건부 최종 데미지 효과가 있으며, 펫 버프로 유지 중이면 중복된다. 시퀀스 등록과 발동은 인게임 검증 전이다.
- 위험 패턴 전에 사용한다. 두 핵심 버프가 쿨타임이면 세 번째 버프만 발동할 수 있다. 무적·의지·판테온은 각각 `D`·`F`, `4`·`5`, `W`로 조작한다.
- 블리츠 실드 VI는 모험가 전사 공용이다. 쓸만한 하이퍼 바디는 최대 HP를 올려 HP 비례 패턴 대응용으로는 적합하지 않다.

### 4-2. 실전 극딜 예시

**후오리진**

```text
1 → W(판테온 VI) → Page Down 키다운 + S 연타 / Z → X → A → 2 → R → 후속 공격
```

**선오리진**

```text
1 → W(판테온 VI) → 2 → Page Down 키다운 + S 연타 / Z → R → 준비된 X / S / A
```

보스와 파티에 따라 오리진·일반 바인드 순서를 조정한다. 익팅의 스틱스 감응은 팩텀 등록 가능 여부 확인 후 적용한다. 수동과 감응은 스틱스 쿨타임을 공유한다. 두 입력의 상대 DPS와 판테온 VI 개방 시 자동 단축키 승계는 미검증이다.

## 5. 변경 이력

- **2026-09-25** 최초 작성. 2026-09-17 본섭 1.2.419 이후 기준.
- **2026-10-23** 키 재설계. 공격 시퀀스 `W → 2`, 엔버링크 `T → W`, 오리진 `Y → 3`, 프로미넌스 `G → R`, 익팅 `R → Page Down`. `Y` 리레 확인, `1` 파운틴, `4/5` 의지, `6` 야누스, `C` 상호작용, `End` 버티컬 커넥트, `-/=` 온·오프, `9` 헤카테, `0` 페미에이션을 배정했다.
- **2026-10-24** 9종 공격 시퀀스에서 파이널 트랜스 직후 로버스트 아머 → 바디 오브 스틸을 넣는 순서를 선택했다. 리레 4 최적성과 홀리 파운틴·솔 헤카테 동시 활성화 시 서버 지연은 미검증이다.
- **2026-11-04** 은월에 맞춰 `1` 극딜·`2` 오리진·`3` 파운틴·`Q` 엔버링크·`W` 판테온·`R` 일반 바인드로 재배치했다. 프로미넌스를 `E → T`로 옮긴 뒤 공격 시퀀스에서 방어 버프 2종을 빼고 `E`에 방어 시퀀스를 제안했다.
- **2026-11-20** `9 ↔ 0`, `E ↔ T` 배치를 교환했다.
- **2026-11-21** `E`에 스틱스 수동키를 배정하고 프로미넌스를 `G`로 옮겼다.
- **2026-11-22** `1` 극딜 시퀀스에 파이널 피규레이션을 추가하고 리레 4를 마지막에 배치했다.
