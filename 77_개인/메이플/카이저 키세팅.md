# 카이저 키세팅

> 기준일: 2026-09-25
>
> 목적: 은월에서 익숙한 키 역할을 최대한 유지하면서, 2026-09-17 본섭 1.2.419 이후 카이저 운용에 맞춘 보스용 키세팅을 고정한다.
>
> **주의:** 실제 보스에서 손에 안 맞는 부분은 변경 가능하다. 특히 오리진/일반 바인드의 세부 순서는 사용하는 극딜 빌드에 따라 달라질 수 있으므로 키 위치와 극딜 순서를 분리해서 기록한다.

## 1. 현재 키세팅

| 키 | 스킬 | 역할 / 메모 |
|---|---|---|
| `A` | 기가 슬래셔 / 드라코 슬래셔 | 상시 평딜. 드라코 사용 가능 시 강화 평딜 |
| `S` | 윌 오브 소드 : 차지 | 20초 주기. 익팅 중 연속 사용 핵심 |
| `X` | 인퍼널 브레스 | 20초 누킹기 |
| `Z` | 윌 오브 소드 : 스트라이크 | **30초** 누킹기 |
| `D` | 드래고닉 이지스 | 능동 무적 / 비상 생존 |
| `F` | 파이로 인스팅트 | 어센트. 강한 독립 공격 + 시전 중 무적 |
| `G` | 프로미넌스 | **60초**. 공격 + 비변신 시 모프 게이지 수급 |
| `Q` | 에르다 노바 | 일반 바인드 |
| `W` | 풀극딜 시퀀스 | 120초 풀극 시작. 엔버링크·변신·극딜 버프 묶음 |
| `E` | 판테온 | 풀극에서 W 직후 사용하는 120초 계열 극딜 보조 |
| `R` | 드라코닉 익스팅션 | 키다운 극딜 본체 |
| `T` | 엔젤릭버스터 링크 | 수동 준극 시작 / 쿨 확인 |
| `Y` | 마이트 오브 노바 | 오리진 |
| `Shift` | 파이널 피규레이션 / 변신 중 텔레포트 | 주력 회피·이동 / 변신 |
| `Alt` | 피어스 러쉬 | 카이저의 표준 돌진 역할. 은월의 공용 돌진 자리 유지 |
| `V` | 블링크 | 공중 체공 |
| `3` | 의지 | 상태이상 해제 |
| `4` | 파운틴 | 설치기 |
| `5 / 6` | 야누스 | 사냥 |
| `Ctrl` | 미정 | 현재 비워둠 |
| `9 / 0 / - / =` | 온오프 계열 | 윌 오브 소드 / 에르다 페미에이션 / 솔 헤카테 / 리셔플 스위치 배치 후보. 세부 순서 미정 |

## 2. 평딜 입력군

평딜 중 자주 보는 스킬은 왼손 하단에 모은다.

```text
A = 기가 / 드라코
S = 윌 오브 소드 : 차지   (20초)
X = 인퍼널 브레스          (20초)
Z = 윌 오브 소드 : 스트라이크 (30초)
```

기본 개념:

```text
A A A...
→ S / X / Z가 돌아오면 사용
→ 다시 A
```

카이저는 극딜에서도 이 평딜 입력군을 그대로 많이 사용한다. 별도의 극딜 전용 공격 버튼을 다수 추가하기보다, 익팅과 극딜 버프 안에서 평소 쓰던 공격기를 몰아치는 구조로 본다.

## 3. 60초 준극

현재 준극 시작 묶음:

```text
T G
→ Z / X / S / A
```

- `T` = 엔버링크: 준극의 실질적인 시작 버튼
- `G` = 프로미넌스: 60초 주기에 같이 털며, 비변신 상태라면 모프 게이지 수급에도 사용
- `Z/X/S/A` = 그 시점에 돌아온 평딜 공격기를 몰아친다.
- 카이저는 별도의 강한 “준극 전용 공격기” 하나를 누르는 구조라기보다 **엔버링크 + 평딜기 몰아치기**에 가깝다.

## 4. 120초 풀극

현재 고점형 입력을 키 기준으로 단순화하면:

```text
W E
→ R 키다운 중 Z + S S S S S S
→ R 해제
→ X A
→ Y / Q ...
```

압축 암기:

```text
WE
R + ZSSSSSS
XA
YQ ...
```

### 역할

- `W`: 극딜 버프/변신 시퀀스 시작
- `E`: 판테온
- `R`: 드라코닉 익스팅션 키다운
- `S`: 익팅 중 윌 오브 소드 : 차지 연속 사용
- `Z`: 익팅 중 윌 오브 소드 : 스트라이크
- `X → A`: 익팅 뒤 브레스 → 드라코
- `Y / Q`: 오리진과 일반 바인드

> **Y/Q 순서는 아직 키세팅의 고정 규칙으로 취급하지 않는다.**
> 고점형·선/후오리진 등 빌드에 따라 일반 바인드를 사용하는 시점이 달라질 수 있다.

## 5. 이동·생존 역할 대응

은월에서 익숙한 손의 의미를 최대한 유지한다.

```text
D      = 무적
F      = 어센트 무적
Shift  = 핵심 회피 / 텔레포트
Alt    = 돌진
V      = 블링크
```

특히 `Alt = 피어스 러쉬`는 은월에서 Alt에 두던 공용 돌진과 역할을 맞춘다.

## 6. 검증·정정 기록

### 현재 기준

- 윌 오브 소드 : 차지 = **20초**
- 인퍼널 브레스 = **20초**
- 윌 오브 소드 : 스트라이크 = **30초**
- 프로미넌스 = **60초**
- 프로미넌스의 과거 무적 역할은 현재 드래고닉 이지스로 분리됨
- 피어스 러쉬는 현재 공격기보다 이동용 돌진기로 취급

### 폐기된 오정보

- ~~윌 오브 소드 : 스트라이크 = 60초~~ → **폐기. 현재 30초**
- ~~프로미넌스 = 현재 카이저 무적기~~ → **폐기. 현재 능동 무적은 드래고닉 이지스**
- ~~Ctrl = 피어스 러쉬 + Alt = 별도 공용 돌진~~ → **폐기. 피어스 러쉬 자체를 Alt의 돌진 역할로 사용**
